# Big Evolution Model

[English](README.md) · Русский

Симуляция искусственной жизни с эволюционирующими нейросетевыми особями, индивидуальным обучением и пространственной памятью в мире на гексагональной сетке.

Особи наследуют параметры мозга, обучаются на личном опыте, запоминают места и конкурируют за возобновляемую пищу. Интерфейс позволяет наблюдать мир, выбирать отдельных особей, изучать их решения и сравнивать эксперименты.

**Статус:** экспериментальный прототип. **Текущая версия:** 0.42.0. **Язык интерфейса:** русский.

В 0.42.0 добавлена таблица выбранной пары A/B: разности, отношения, проценты и приближённые парные ДИ. Видны полные пары, попытки и пропуски; исправлено наложение названий на числа под графиками. [Протокол](docs/updates/v042-paired-comparison.md).

В 0.41.0 добавлены население, приближённые доверительные полосы, гистограммы сравнения и численные сводки на выбранном периоде. Панель сдвигает графики, а большой JSON собирается порциями с прогрессом и обработкой ошибок. [Протокол](docs/updates/v041-statistics-bands-export.md).

В 0.40.0 миры опытов сгруппированы по сочетаниям настроек, управление статистикой собрано в одной левой панели по нажатию. Добавлены модальные уведомления, явные seed карты/пищи/жителей и пояснения к экспортам. [Протокол](docs/updates/v040-experiment-organization.md).

В 0.37.1 можно закрепить максимальный возраст на кривой дожития для сравнения групп рождения. Переключатели линий остаются видны при прокрутке статистики. [Протокол](docs/updates/v037-fixed-survival-axis.md).

В 0.37.0 пищевые островки перемещаются целыми группами. Добавлены графики размножения, наследуемых свойств, распределения чувствительностей и потенциальной выработки пищи; темп четыре подшага в секунду. [Протокол](docs/updates/v037-moving-islands-statistics.md).

## Запуск в браузере

Открыть [Big Evolution Model](https://griseus4.github.io/big-evolution-model/) и нажать **«Наблюдать»**. Установка не требуется; расчёт выполняется на вашем устройстве.

## Локальный запуск

После скачивания и распаковки репозитория:

1. Установить Python 3.
2. Открыть терминал в папке проекта и выполнить:

   ```sh
   python -m http.server 8000 --bind 127.0.0.1 --directory dist
   ```

3. Открыть [http://127.0.0.1:8000/](http://127.0.0.1:8000/) в браузере.
4. Нажать **«Наблюдать»**.

Терминал оставить открытым. Node.js нужен только разработчикам для проверок.

Приложение написано на JavaScript, HTML и CSS с Canvas; внешние библиотеки и этап сборки для запуска не требуются. Python используется для локального HTTP-сервера и инструментов разработки.

## Что реализовано

- Гексагональная карта с реками, озёрами, островками пищевых источников и отдельными кустами.
- Наследуемый нейросетевой мозг и личное обучение Expected SARSA(λ).
- Краткая и долгая память мест. Личный опыт и найденные координаты потомкам не передаются.
- Видимость источников пищи, включая пустые, и локальное восприятие других особей.
- Энергия, пищеварение, переносимый запас, голод, длительные действия, добровольное рождение и предел возраста.
- Воспроизводимые условия по seed, экспорт и анализ геномов, проверки механизмов и сравнение производительности версий.
- Координатор мира отдельно от интерфейса браузера; до шестнадцати постоянных Worker считают личные мозги, память и обучение. В новом опыте доступны Авто /1 /2 /4 /6 /8 /10 /12 /14 /16 вычислителей.

По умолчанию карта48×32,150 основателей, лимит начала родов1000 особей и384 источника пищи. Лимит не гарантирует устойчивую численность. Текущий геномv13 содержит1918 числа:1827 параметров основного мозга,12 свойств,77 параметра внимания и2 регулятора мутаций.

В0.34.0 действия занимают время, могут прерываться и пересматриваться по запросу малого мозга. Социальные группы и вожак — долгосрочное направление исследования. Модель использует упрощённые физиологию и экологию.

## Проверки

Для проверки распакованного архива или нового репозитория нужны Python3 и Node.js:

```sh
python tools/verify-local.py --source-only
```

Отдельная группа:

```sh
python tools/verify-local.py --source-only --only static
python tools/verify-local.py --source-only --only mechanisms
```

Режим `--source-only` проверяет SHA-256 расчётных снимков и исполняемые механизмы. Сравнение с историческими Git-коммитами и проверка Git diff явно пропускаются: история в ZIP не входит. В исходном рабочем репозитории с полной историей используется прежняя команда `python tools/verify-local.py` без этого флага.

Длительные эволюционные опыты и полные серии замеров запускаются отдельно.

## Структура и документация

- `dist/` — рабочие JS-модули игры и статические ресурсы; эта папка обслуживается HTTP-сервером.
- `docs/` — описание модели, архитектура, решения и история обновлений.
- `tests/` — проверки Node.js.
- `tools/` — локальная проверка, анализ, экспорт исходников и упаковка.

## Лицензия

Версия0.32 вводит10 подшагов на единицу времени, длительности и прерывания действий, наследуемую сеть внимания и энергетическую цену решений. Старые геномы не запускают новый мир. Лимит запрещает начало новых родов, уже начатые могут завершиться сверх него.

Версия0.33 распределяет личные мозги и память между вычислителями, сохраняя модель0.32, обучение и RNG. В новом опыте доступны Авто /1 /2 /4 /6 /8 /10 /12 /14 /16; один оставляет последовательный расчёт. [Реализация и короткие измерения](docs/updates/v033-parallel-world.md). Выпуск пока локальный.

Сравнение режимов: «Испытания → Замеры скорости → Число вычислителей · один мир». Выберите одну нагрузку150/400/1000, несколько чисел вычислителей и повторы. Каждый режим получает одинаковый мир; таблица показывает шаги/с и совпадение итогов. [Описание0.34.0](docs/updates/v033-worker-counts.md).

В0.34.0 выбор перенесён в «Мир → Производительность → Вычислители», рядом подвкладка «Измерения». Применение переключает живущий мир без перезапуска. В замерах под каждой версией галочки поддерживаемых чисел, оценщики один раз на версию; таблица показывает ускорение и эффективность без автоподбора. Крупные круглые бегунки, центральный период10…300. [Протокол](docs/updates/v033-live-controls.md).

Отдельная возрастная кривая имеет собственный выбор группы рождения и показывает границы неизвестного дожития живых пунктиром. Показатели относятся ко всей жизни выбранных особей; пища — к выбранному времени мира. Таблица сохраняет внутреннюю прокрутку и страницы по50 строк.
