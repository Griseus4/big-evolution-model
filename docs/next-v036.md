## Числовое следствие выбранной редкости

Для обычного нормального распределения относительного изменения r с центром0 условие P(r≤−0,5)=0,02 даёт sigma=0,5/PhiInverse(0,98)=0,2434572198. Примерно68,27% предложений находятся в пределах±24,35%,95% —±47,72%. Таким образом,1/50 сильных обеднений означает заметный разброс обычных изменений; он не совместим с почти всеми изменениями около±5% в одном нормальном распределении. Это аналитический расчёт через Python statistics.NormalDist, не прогон мира. Нижний порог применяется после случайного предложения и меняет распределение фактических изменений; отрицательная предложенная выработка не должна попадать в мир. Прежнее предложение нормального логарифма — не утверждённый контракт и даёт другие числа/средний дрейф.
