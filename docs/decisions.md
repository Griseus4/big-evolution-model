# Действующие решения и принятые направления

Короткий индекс, не стенограмма. Числа механик — [действующая модель](mechanics-reference.md), правила работы — [AGENTS](../AGENTS.md). [Полная история прежних формулировок](archive/context-2026-10-18/decisions.md) сохранена; её отменённые условия не действуют.

| Решение | Смысл и действующий источник |
| --- | --- |
| Эволюция без готовой стратегии | Наблюдать обучение/отбор к социальному поведению; не подменять их скриптом стаи. Память и обучение сохранять. [Механики](mechanics-reference.md#мир-и-цель) |
| Личные знания отдельно от генома | Нет наследования найденных координат/опыта и скрытых глобальных входов. [Память](mechanics-reference.md#память-и-обучение) |
| Гексы и длительности | Дискретное пространство/подшаги действуют сейчас; непрерывные координаты/время — будущее отдельной ветки. [Время](mechanics-reference.md#действия-и-время) |
| Основной и малый мозг | Платный основной выбор знает процесс; малый наследуется, не обучается за жизнь. [Мозг](mechanics-reference.md#мозг-геном-и-ощущения) |
| Дефицит оплачивается здоровьем | Неоплаченные затраты не бесплатны, отдельного второго голодного штрафа нет. [Энергетика](mechanics-reference.md#энергетика) |
| Боль и риск удалены | Не возвращать старую механику из исторической спецификации. [Мир](mechanics-reference.md#мир-и-цель) |
| Подробное локальное наблюдение | Доступна деятельность соседей без социальной памяти и готовых взаимодействий. [Восприятие](mechanics-reference.md#восприятие-и-соседи) |
| Автоматика с целями | После подготовки колебания около пользовательских целей, жёсткие границы и поэтапная коррекция. [Окончательный контракт](next-target-environment.md), [выпуск](updates/v038-target-food-environment.md) |
| Новое сохранение без старой схемы | Полный мир новой схемы точно продолжается; старые полные файлы не поддерживать. Не переносить это автоматически на геномы. [Сохранения](mechanics-reference.md#сохранения-исполнение-и-испытания) |
| UI наблюдает живой мир | Переключение разделов/справка/скрытие не ставят программную паузу; медленная карта показывает подшаги. [Наблюдатель](mechanics-reference.md#наблюдатель-и-статистика) |
| Эксперименты как будущее направление | Отдельное сравнение статистики поддержано, реализация ещё не разрешена. [Вопросы будущего контракта](experiment-comparison-plan.md) |
| Компактный контекст | Пользователь разрешил убрать историю из входных файлов; один контракт обновляется на месте, готовность не равна разрешению кода. [Порядок работы](workflows/context.md), [протокол уборки](updates/v038-agent-context.md) |

Новые решения добавлять только при изменении направления/контракта, а не после каждого ответа. Подробный ответ сохраняется в одном тематическом документе. Выполненное убирать из активной задачи; основания остаются в протоколе и истории Git.

Сравнение итогов: один выбранный результат на исходный повтор, даже при разных попытках/seed. Это настройки вместе с правилом повторов, вымирания видимы. Организация — 0.40.0, графики/полосы — 0.41.0; [таблица пары 0.42.0](updates/v042-paired-comparison.md) считает разность/отношение/процент и совместные ДИ на полных парах каждой метрики. Пропуски показаны, остальные миры остаются в общей статистике. Порог — пять пар, при малом n осторожное чтение; нулевая/неопределённая база не даёт ложный конечный ДИ отношения. Население: временные средние миров с равным весом; медианы особей сохраняют переключатель. График разности отложен. [Контракт](next-experiment-statistics-ui.md).

Конструктор 0.39: общие seed/варианты, до трёх попыток с видимыми вымираниями, два режима весов, безопасная пауза/возобновление основного мира. [Принятый контракт](experiment-comparison-plan.md).

Редактор: один список параметров, все сочетания до 64 на seed, планы v2 без старых шаблонов. С 0.39.2 общие география и пищевая среда seed 42, разные жители между повторами/попытками и парные старты внутри повтора. Различия исследуемых пищевых настроек и фактического сбора сохраняются. [Контракт](next-experiment-factors.md).
