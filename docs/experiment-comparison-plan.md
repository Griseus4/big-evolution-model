# Контракт исполнителя опытов 0.39.0

Редактор и формат планов заменены в [0.39.1](next-experiment-factors.md); ниже сохранён контракт исполнения, повторов и статистических весов.

Статус: выполнен в [0.39](updates/v039-experiment-constructor.md); дальнейшие изменения редактора/статистики описаны в протоколах выпусков. Диагностический микротест ощущений остаётся [отдельным направлением](next-feeling-behavior.md).

## План и варианты

Вкладка «Опыты»: шаблоны, конструктор, запуски, прежние замеры скорости и проверки. Общие настройки плюс названные варианты с отличиями. По умолчанию пять миров **на вариант**, 20 000 Т. Основные seed редактируются, стандартная последовательность сохраняет начало при увеличении числа миров; рандомизация заменяет всю последовательность. Матрица из трёх seed на каждый мир определяется до запуска и одинакова для вариантов.

Основатели/лимит из WORLD_DEFAULTS (150/1000); география фиксирована. Редактируются пороги энергии/здоровья размножения, зрелость и интервал рождения; цена/длительность родов и энергия ребёнка прежние. Начальная пища и настройки автоматики общие либо переопределены вариантом. Пять подготовительных событий, затем колебания. Память, личное обучение и мутации переключаются независимо. Мутации выключены — дети копируют геном, личный опыт не наследуется. Допускается текущая основа генома; расширенный редактор регуляторов отложен.

## Попытки и исполнение

Вымирание даёт до трёх попыток с новыми seed всего мира. Успешная попытка завершает группу; если все вымерли, выбирается самая длительная по модельному времени, при равенстве первая. Все попытки сохраняются, вымирания отмечаются красным и текстом. Техническая ошибка не становится вымиранием или скрытой повторной попыткой.

Общий бюджет учитывает один поток последовательного мира либо k владельцев мозгов плюс координатор. Сначала независимые миры из очереди; после её исчерпания свободный бюджет усиливает оставшиеся достаточно большие миры до выбранного максимума. Фиксированный режим также доступен. Перестройка только между шагами с синхронизацией личного состояния, без изменения RNG; не обещается оптимальность для любого ПК.

Основной мир явно приостанавливается; запуск/подшаг/перезапуск/загрузка во время серии блокируются. После окончания или остановки всех задач ранее работающий мир возобновляется; ранее остановленный остаётся на паузе. При ошибке запуска состояние восстанавливается. Исходные настройки серии копируются и не меняют основной мир.

## Статистика и хранение

Одна страница «Статистика»: текущий мир, сводка варианта, отдельная попытка, сравнение вариантов. Сводка берёт выбранные итоговые попытки, при выполнении серии она предварительная. Живые данные отдельной выбранной попытки обновляются примерно раз в пять секунд, с передачей только новых завершённых строк. Полные мозги не передаются.

Два режима: равный вес миров (по умолчанию) и равный вес особей. Для каждой метрики/когорты масса непустого мира равна 1; медиана определяется по исходным взвешенным значениям, не по средним медиан. Недостающие значения исключаются из метрики. Цензурирование живых сохраняется. Пища усредняется по общему наблюдаемому времени миров, с равным весом миров. Сравнение использует один выбранный показатель на вариант; таблица, индивидуальные подсказки и маркеры относятся к первому варианту, что явно подписано.

Результаты сохраняются в IndexedDB по завершённым попыткам; общий отчёт содержит ссылки на их записи. Экспорт/импорт JSON, планы JSON и собственные шаблоны. Это результаты, а не полные миры для продолжения: закрытые/прерванные серии не возобновляются. Незавершённые живые данные до окончания попытки могут оставаться только в памяти страницы. При недоступности/переполнении хранилища показано сообщение, JSON остаётся доступен.
