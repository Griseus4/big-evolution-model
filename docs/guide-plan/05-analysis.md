## P20 — средние, медианы, веса и интервалы

**Зависимости:** P18–P19. **Статус:** выполнен в 0.54.15 — [протокол E](../updates/v054-guide-analysis.md).

Источники: `weighted-statistics.js`, `statistics-estimates.js`, `statistical-series.js`, `statistical-blocks.js`, `statistics-format.js`, клиенты/Worker статистики.

Для каждого режима точно определить оцениваемую величину: все особи, равный общий вес миров, сначала значение мира, затем распределение миров. Не объединять в одну «медиану» разные алгоритмы. Объяснить обработку пустых миров, число независимых единиц, resampling и уровень ДИ, вырожденную выборку, точечную полосу и разброс миров. Среднее средних равно общему среднему только при соответствующих весах.

**Пример:** миры возрастов [1,2,3] и [1,2,3,4,5,6,7,8,9]: вывести результат каждого реально поддерживаемого режима рабочим алгоритмом, включая его правило взвешенной медианы. Это учебные входы, не результаты опыта. Для bootstrap показать смысл повторного выбора единиц, не выдавать конкретный интервал без расчёта.

**Готово:** таблица «режим → единица → вес → оценка → ДИ»; асимметричный ДИ не заменён произвольным ±. Нулевой наблюдаемый разброс не назван доказательством точности. Проверки: `statistics043.test.mjs`, `statistical-ui041.test.mjs`, текущие weighted/estimates случаи. Для внешних статистических утверждений использовать первичный источник; он не заменяет проверку алгоритма приложения.

## P21 — группы и сравнение выбранной пары

**Зависимости:** P16, P20. **Статус:** выполнен в 0.54.15 — [протокол E](../updates/v054-guide-analysis.md).

Источники: `experiment-grouping.js`, `statistical-blocks.js`, `experiment-statistics.js`, `pair-statistics.js` — `preparePairSide`, `estimatePair`; `pair-series.js`, `pair-comparison-ui.js`, `history-differences-ui.js`.

Показать группировку по обучению либо времени усвоения, состав группы и равновесность вкладов вариантов/повторов по реализации. Различить общий фильтр и группировку. Для A/B объяснить B−A, отношение, процент, общий выбор пары, полные пары по конкретному показателю, несовпавшие seed после попыток, неполные блоки, ненадёжную/нулевую базу, ДИ разности.

**Пример:** шесть вариантов «обучение × три времени усвоения» сгруппировать двумя способами; одна отсутствующая метрика показывает, какие повторы использованы. Сверить, не изменяет ли перекрытие групп зависимость оценок; если ограничено — указать ограничение, не вводить новый метод.

**Готово:** читатель может получить прежние графики по группам и объяснить состав сравнения. Проверки: `chart-catalogue048.test.mjs`, `chart-context049.test.mjs`, `pair-statistics042.test.mjs`, `statistics043.test.mjs`.

## P22 — шаблоны, формулы и локальные настройки графика

**Зависимости:** P18–P21. **Статус:** выполнен в 0.54.15 — [протокол E](../updates/v054-guide-analysis.md).

Источники: `chart-catalogue.js`, `chart-catalogue-ui.js`, `chart-context.js`, `chart-pins-ui.js`, `chart-local-renderer.js`, `analysis-expression.js`, `analysis-builder-core.js`, `analysis-projection.js`, `catalogue-expression-client.js`. Проверить фактическую точку монтажа; прежний `analysis-builder-ui.js` не описывать как текущий экран без подтверждения.

Описать стандартные шаблоны, копии/скрытие/восстановление, категории, формулу, поле, группировку, ось, агрегатор, фильтры и закрепления. Показать приоритет локального закрепления над общим фильтром, ошибки формулы, деление на ноль/пропуски, ограничения синтаксиса и доступных данных. Изменение шаблона не создаёт отсутствующие первичные наблюдения.

**Пример:** средний/медианный возраст второго, затем третьего ребёнка — только через реально доступные поля/выражения; явно описать, кто исключается, если нужного ребёнка не было. Если точный сценарий не поддерживается, показать предел и зарегистрировать пробел функции отдельно, не реализовывать новую механику сбора.

**Готово:** пошаговая инструкция создания и применения шаблона с ясной выборкой. Проверки: `analysis-builder047.test.mjs`, `chart-catalogue048.test.mjs`, `chart-context049.test.mjs`; для живого обновления ссылка на P26.

## P23 — сохранения, архивы и загрузка частями

**Зависимости:** P12, P15–P22. **Статус:** выполнен в 0.54.15 — [протокол E](../updates/v054-guide-analysis.md).

Источники: `world-save.js`, `state-codec.js`, `world-files-ui.js`, `genome.js`, `experiment-plan.js`, `experiment-archive.js`, `experiment-store.js`, `json-export.js`, `analysis-projection.js`, `experiment-ui.js` — подготовка статистики.

Разделить назначение полного мира, генома, плана, отчёта JSON, .beexp и проверок/замеров. Для каждого: состав, версия/совместимость, что можно продолжить, что импортируется, валидация до замены текущего состояния. Объяснить таблицы/общую схему/сжатие/блоки, ленивые окна, пропуски против ещё не загруженных данных, экспорт полного содержания. Не называть JSON потоково разбираемым, если код материализует его целиком.

**Готово:** таблица выбора файла, схема загрузки и конкретные границы совместимости со ссылками на валидаторы; отмена/ошибка не описана как успешный импорт. Тесты: `environment-save.test.mjs`, `experiment-storage045.test.mjs`, `genome-experiments044.test.mjs`. Не добавлять миграции и не менять формат.
