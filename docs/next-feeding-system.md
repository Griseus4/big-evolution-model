# Будущее обновление питания

Статус: отложенное направление пользователя от 25.10.2026; правила не определены, реализация не поручена.

Нужно обсудить систему питания хищников, различные типы пищи, включая траву, и их усвоение. Текущий приоритет — [локальный поиск по справочнику и коду](next-performance-map.md#внутренний-поиск-по-проекту--обсуждение). Пользователь предложил вернуться к питанию примерно через одно обновление; это ориентир очередности, не назначенный выпуск.

До кода согласовать, откуда берутся разные виды пищи, кто способен их потреблять, как устроены поедание и усвоение, энергетические балансы и наследуемые различия. Хищничество и новые типы пищи не считать действующими только из-за этой записи. Не добавлять боевые действия или траву молча в текущую модель.

Следующий шаг: после поиска обсудить конкретный механизм и разделить изменения на проверяемые этапы. Действующая система остаётся в [описании механик](mechanics-reference.md).
