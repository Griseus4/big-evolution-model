# 0.25 — текущее восприятие соседей

Новые основатели получают геном v8 (35 → 16 → Q; 606 чисел). Три новых входа: количество других на своей клетке, в клетке оцениваемого действия и во всём обзоре. Нет готового бонуса толпе или одиночеству. Своя клетка + шесть соседних, круговой обзор.

На соседних клетках — анонимные количества; на своей клетке — текущие ID в панели «Ощущения и соседи». Личной истории встреч, социальной памяти и новых действий нет. v7 остаётся с прежними 32 входами и 558 числами без автоматического расширения. Анализатор понимает v8 и не сопоставляет смещённые параметры v7/v8 как одинаковые гены.

Индекс клеток обновляется после каждого перемещения/рождения/смерти. Обзор выполняет постоянное число запросов, не перебирает всё население. Полный список контактов строится только по запросу панели. Добавлены 15 механизмов, всего 158. Выполнены статические проверки; исполняемые проверки и бенчмарки запускает пользователь. Измеренного ускорения или преимуществ поведения пока не заявлено.

Новая серия производительности `neural-neighbours-v1`, нагрузки `fixed-neighbour-workloads-v1`, исходный снимок 0.25. Старые снимки оставлены в Git, из текущих ресурсов убраны. Старые JSON читаются, сравнение разных серий запрещено.

Будущие идеи отдельно: наследуемая частота мутации и характеристики тела. Правила питания/рождения/процента мутаций в этом выпуске сохранены.
