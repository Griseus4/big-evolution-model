# 0.26 — наследуемая изменчивость

## Согласованный контракт

Пользователь утвердил весь контракт 14 октября: два регулятора, случайные индивидуальные значения основателей, ненулевой фон, относительное изменение регуляторов, сохранение медленных свойств памяти/обучения и явное преобразование старых файлов. Новые действия, характеристики тела и изменения мозга не входят в патч.

Начальные вероятности 0,1…10%, силы ±0,05…1 выбираются равномерно по логарифму независимым RNG `mutationRandom`. Это начальные условия, не потолки дальнейшего развития. Старые исходные параметры мозга и позиции при том же seed не сдвигаются. Следующее потомство эволюционирует по индивидуальным значениям; общие 2/6/15% не задают новый опыт.

## Физика наследования

- Два гена в конце массива: лог-координата вероятности и логарифм силы. В сеть не входят и TD их не меняет.
- Вероятность `p=0.0001+(1-0.0001)*sigmoid(g_p)`. Полный ноль невозможен; максимум вероятности 1.
- Сила `s=exp(g_s)`, минимум 0,000001 в единицах параметра мозга. Этот маленький положительный минимум выбран для реализации утверждённого запрета нулевой силы. Верхний предел логарифма — представимость конечного Number, не биологический потолок. Прежние числа мозга остаются в −8…8.
- Мозговые гены: с вероятностью p прибавляется равномерное число в [−s,s]. Чувствительность/пластичность/память: вероятность `max(0.0001,p/4)`, прибавка [−s/5,s/5]. На нижнем фоне соотношение вероятностей уже не 4:1.
- Сами регуляторы меняются с обычной p: лог-шаг `u*log(1+s)`, где u равномерен в [−1,1]. Это относительный масштаб, без отдельной гарантированной мутации. Все p/s родителя считываются один раз **до** прохода по генам; регуляторы ребёнка управляют уже его потомством.
- Изменение среды не меняет p/s за жизнь. Личное обучение не наследуется и регуляторы не переписывает.
- Галочка «мутации выключены» — явный контроль эксперимента, копирует полный геном без изменений, включая регуляторы. Ненулевой фон действует при включённых мутациях, а не отменяет эту галочку.

## Формат и совместимость

Геном v9 у нового случайного основателя: **608 чисел**, прежний мозг 35 → 16 → Q / 593 параметра / 13 свойств + 2 регулятора. Мозг сохранён полностью. Явно преобразованные v7 имеют 560 чисел и старую сеть 32 → 16 → Q; преобразованная таблица v6 — 574. Схема сети и тип мозга в JSON определяют основу, `mutationSchema=heritable-log-mutation-v1` — хвост. Старые v1–v8 импортируются по прежним правилам, без автоматического хвоста.

Галочка преобразования доступна отдельно в старте обычного мира и длинных испытаний. Добавка одной общей пары к сохранённой основе создаётся один раз на мир и одинакова для всех его основателей. Сам загруженный массив/файл не переписывается. Обычный случайный старт получает индивидуальные пары. Анализатор показывает сырой лог-ген и расшифрованные проценты/силу; отсутствие в старом файле — null. Сравнение одной основы до/после преобразования сохраняет прежние общие веса.

## Стоимость и проверки

Два дополнительных числа на геном, два броска при создании основателя и два дополнительных решения о мутации при рождении. Профиль декодируется один раз на рождение, не на каждый параметр. Нейросеть и её входы/градиенты не увеличены. Уровень мутаций влияет на число дополнительных случайных прибавок. Измеренного ускорения/регресса или полезности изменчивости пока нет.

Подготовлено **170 механизмов**, из них 12 новых: независимость исходных потоков и диапазоны, минимумы, родительский профиль, отсутствие принудительных мета-мутаций, относительные шаги, три адаптера, явное преобразование, выключение/наследование, валидация, анализ, задания/восстановление RNG и повторяемость миров/балансы. Агент не запускал тесты/миры; выполнены только статические проверки.

Новая серия скорости `neural-heritable-mutation-v1`, нагрузки `fixed-heritable-mutation-workloads-v1`, исходный снимок 0.26. Старые отчёты/серии читаются для истории, но не сравниваются с этой моделью как оптимизация. Снимок 0.25 сохранён в Git, из текущих ресурсов удалён.

## Пользователю

1. Обновить страницу, выполнить «Испытания → Проверка механизмов» и скачать JSON.
2. Начать случайный опыт: в «Житель → Свойства» видны индивидуальные вероятность/сила. Экспорт выбранного — v9, анализ показывает два свойства.
3. Загрузить старый геном: без галочки он остаётся прежним; с галочкой старый мозг сохранён, экспорт v9 имеет два новых числа. Проверить и обычный мир, и основу длинных испытаний.
4. Для наблюдения отбора: несколько seed, 100000 шагов, память+TD, мутации включены, сохранение образцов геномов. Вымирание допустимо; не требовать обязательного увеличения или уменьшения вероятности. Сравнивать исходные/последующие распределения p/s и длительность жизни/потомство по данным, не по ожидаемой стратегии.
