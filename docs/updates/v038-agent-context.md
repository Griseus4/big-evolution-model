# Организация контекста агента после 0.38.0

Статус: выполнено локально. Это изменение документации/проверок, не новая игровая версия и не публикация.

## Объём

Пользователь предложил экономить контекст и обновлять данные агента при обсуждениях/патчах, затем поручил реализовать предложенную уборку. Корневой AGENTS теперь содержит постоянные правила; START_HERE — текущий статус и маршруты. Справочник механик и архитектура описывают действующий код по темам. Индексы решений и идей отделены от стенограмм. Один тематический контракт обновляется на месте; готовность не равна разрешению реализации.

Добавлены [порядок контекста](../workflows/context.md), [локальный цикл](../workflows/local.md), [шаблон контракта](../templates/contract.md) и [контрольная запись](../work/current.md). После содержательного обсуждения меняется контракт, а не несколько полных журналов. Завершение/документация/производные архивы готовятся одним проходом; новый чат может продолжить по записи без пересказа пользователя.

## История и ссылки

Шесть исходных документов сохранены в [историческом архиве](../archive/context-2026-10-18/README.md). В снимках добавлены историческая пометка и исправленные относительные Markdown-ссылки; убраны лишние пустые строки в конце двух файлов. Содержание вне ссылок сохраняется. Индекс содержит исходные SHA-256. Удалённые из текущих файлов старые якоря перенаправлены в исторические снимки. Имена текущих документов не менялись; старые ссылки source?file продолжают открывать эти имена.

Действующие ограничения сохранены: отдельное разрешение новой механики/публикации, короткие локальные проверки разрешены, долгие опыты отдельно; геном/личный опыт и владельцы состояния разделены; скрытые сведения/готовая стратегия не добавляются; снимки неизменяемы. Старые противоположные запреты и отменённые версии остаются только историей.

## Проверки и границы

`check-agent-context.py` ограничивает объём семи входных файлов в символах и требует непустые поля/известный статус контрольной записи. Он не оценивает истинность текста и не разрешает код. `check-project-docs.py` проверяет все ссылки/якоря, а кодовые факты текущей модели ищет в справочнике механик вместо стартового файла/исторического описания.

`python tools/verify-local.py --only docs` выполняет ссылки, контекст и git diff. Это отдельный scope; он включён также в обычные статические/полные проверки. Чистая уборка документов не требует повторного запуска 188 игровых тестов/42 механизмов; их прежний результат остаётся в протоколе выпуска 0.38.0.

Обязательные AGENTS + START_HERE сокращены с 32 286 до 7 467 символов: на 76,9%. Это измерение текста, не токенов или времени ответа. Подробности читаются только по маршруту задачи.

Проверки: все шесть архивных текстов совпали с исходными после исключения служебной исторической пометки, адресов Markdown-ссылок и завершающих пустых строк; SHA-256 исходных копий совпали с индексом. Валидатор на временных фикстурах отклонил шесть ошибок: превышение размера, отсутствие/пустоту следующего шага, дублирование/неизвестный статус, отсутствие маршрута к контрольной записи. Проверка документов подтвердила ссылки/якоря и соответствие основных фактов экспортам кода. Результаты локально: `.transfer/context-cleanup-validation.json` и `.transfer/verification-latest.json`.

Хеши 627 файлов игры и расчётных снимков совпали с прежней сборкой. Отпечаток остаётся `284eef996b4c68c9e593623d7242c9bec935cc7d9745dd8c7efd87469a8124e1`, версия 0.38.0. Производные копии и архивы обновляются общими инструментами заключительного прохода.

Игровые JS/HTML/CSS, форматы и расчётные снимки не менялись; корневой неотслеживаемый LOCAL-CODEX-START.md не редактировался. Глобальные настройки/память агента и удалённые сайты не менялись.
