# 0.55.2 — карточки схем генома и проверка затрат

Стандартные наследственные карточки отбираются по полям источника до фильтра периода и происхождения жизней. Мир v16 показывает раздельные пары мутаций и текущие показатели структуры; прежние общие показатели остаются для исторических отчётов. Смешанные источники сохраняют оба набора, пользовательские копии не удаляются. Отсутствующие исторические значения не превращаются в нули. Нового сбора действующих элементов сети этот патч не добавляет.

Координатор проверяет весь ответ Worker до выбора и оплаты: конечную положительную цену каждого доступного основного выбора, положительную цену реально выполненной проверки диспетчера, конечную неотрицательную цену обучения и наличие обязательного решения. Нулевой расход отсутствующей проверки допустим, в том числе при первичном выборе и защищённых родах. Несовместимый протокол сразу останавливает пул. Недопустимые затраты не заменяются усреднёнными.

Правила эволюции и сила мутаций сохранены. Старую нулевую историю затрат восстановить по агрегатам нельзя. Источник нулевых полей в прежнем браузерном запуске не установлен; защита закрывает воспроизведённый путь принятия некорректных ответов. [Диагностика](../brain-statistics-diagnostics.md).

## Проверки

Регрессии: текущие/старые/смешанные схемы, переключение источника в настоящем модуле UI с управляемым DOM; реальные Node Workers с подменёнными ценами выбора, проверки и обучения. Локальный/параллельный расчёт проверяется существующими тестами эквивалентности. Итоговый прогон записан в [контрольной записи](../work/current.md). Настоящая браузерная отрисовка и длительная эволюция не проверены.

Пособие: сверены главы о цене мозга и статистике; добавлено объяснение остановки при ошибочном ответе. Формат генома v16 и полного мира v4 сохранён. Серия скорости прежняя; новый неизменяемый снимок фиксирует защиту исполнения, замеры скорости не проводились.
