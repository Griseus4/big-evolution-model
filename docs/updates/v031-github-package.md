# 0.31.3 — архив исходников для GitHub

16 октября2026. Пользователь поручил подготовить архив текущей версии для загрузки на GitHub. Это локальная подготовка, не создание репозитория, push или публикация сайта. Механика/модель0.31.3, геномv11 и неизменяемые расчётные снимки остаются прежними.

## Состав и изменения

- Корневой README на английском, README.ru.md на русском с коротким запуском через Python. Старый корневой README сохранён как [исторический документ](v031-readme-before-github.md); его прежние числа не выдаются за текущую модель.
- package.json получил имяbig-evolution-model и версию0.31.3; private:true сохранено как свойство npm-пакета. GitHub-видимость этим не задаётся.
- Общий .gitignore исключает .transfer, локальные настройки, Python-кэши и releases. Прежний отслеживаемый .openai/hosting.json не удаляется из рабочего репозитория, но исключён из архива.
- [package-github.py](../../tools/package-github.py) собирает ZIP по разрешённому списку канонических файлов и нужных ресурсов страницы исходников. .git, прежний хостинг, отчёты, профили браузера и переносной bundle не включаются. Проверяются CRC, совпадение содержимого с рабочими файлами/вложенным исходным ZIP и SHA-256 архива.
- История Git в ZIP не переносится. В verify-local добавлен явный --source-only: SHA-256 снимков и исполняемые проверки сохраняются, историческое сравнение с Git и Git diff явно пропускаются и отмечаются в отчёте. Обычный режим в исходном репозитории по-прежнему требует Git и проверяет историческое происхождение снимков.
- Лицензия не выбиралась, скриншот/CI не добавлялись, новая временная модель не реализовывалась. Отложенный вопрос пользователя о цели действия сохранён в [контракте](../next-action-time.md).

## Воспроизведение упаковки

```sh
python tools/export-source.py
python tools/package-github.py
```

Результат: releases/Big-Evolution-Model-v0.31.3-GitHub.zip и соседний SHA-256. Сначала распаковать; загружать содержимоеbig-evolution-model в корень нового репозитория. [Инструкция](../github-upload.md).
