# 0.58.0 — дробные приёмы пищи без потери остатка

Дата: 03.11.2026. Пользователь поручил дробное поедание с сохранением остатка, снятие предела порций за приём и подтвердил неизменное время еды. [Контракт](../next-feeding-system.md#уточнение-после-0572-объём-одного-приёма-пищи).

## Поведение

При завершении еды переносится минимум запаса выбранного вида пищи и свободного объёма желудка. Из инвентаря списывается только проглоченное количество. Например, при запасе 3 и свободном месте 0,7 порции житель съест 0,7 и сохранит 2,3. Полный желудок ничего не списывает.

Отдельного предела числа порций за приём нет. Действие по-прежнему выбирает один вид пищи. Вместимости запаса и желудка сохраняют физический предел. Длительность берётся из eatSteps и не зависит от объёма; прежние моторная ставка и порядок завершения сохранены. portionPerAction теперь ограничивает сбор и выкладывание.

Мясо списывается из своего контейнера в том же фактически съеденном количестве. Остаток продолжает портиться по прежним правилам; приём пищи не обновляет его календарь. В реестрах потребления учитывается проглоченный объём, потерь остатка при еде больше нет.

Калькулятор оценивает сбор запаса перед одним приёмом пищи. Число сборов усредняется по длинной последовательности с сохранением дробных остатков; время еды оплачивается один раз на приём. Объяснение этого сценария показано под таблицей. Обновлены статья питания, выжимка ссылки, название ограничения и подсказки.

## Данные и стоимость

Геном v18, полный мир v5 и план v4 сохраняют формат. Старые сохранения v5 загружаются: следующие приёмы выполняются по новому правилу, уже накопленная история потерь остаётся прежней. Исторические отчёты не переписываются. Формат настроек браузера не меняется.

Перенос любого количества выполняется за O(1), без цикла на порцию и без новых аллокаций. Кольцо желудка и сообщения вычислителей не расширяются. Это новая модель питания, а не оптимизация старой траектории: отдельная серия fractional-meals-v1, неизменяемый эталон 0.58.0 из commit `a695ba8`; нагрузка physiology-workloads-v1 сохранена.

## Проверки

Короткие проверки охватывают все три вида пищи, дробный остаток, пустой запас, полный желудок, приём 12,5 порции за фиксированное время, моторную цену, реестры энергии/ткани/пищи, загрузку мира v5 и калькулятор с малым пределом сбора. Полный verify-local.py прошёл: **516/516 тестов, 53/53 механизмов**, статические связи, документы/бюджеты инструкций, Git/SHA неизменяемых снимков, инициализация, четыре HTTP-проверки запускателя и Git diff. [Общий отчёт](../analysis/v058-verification.json), [механизмы](../analysis/v058-mechanisms.json).

В отдельном headless Chrome загружен мир перед едой: за два ручных подшага проглочено 0,7 порции, в запасе осталось 2,3, желудок заполнен до 3. Проверены калькулятор и подсказка нового ограничения, сохранено фактическое состояние после еды. Ошибок JavaScript нет. [Отчёт браузера](../analysis/v058-browser.json). Это не проверка Opera или всех размеров экрана. Длительные опыты не запускались.
