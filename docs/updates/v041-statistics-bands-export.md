# 0.41.0 — графики, доверительные полосы и большой JSON

Статус: реализовано локально; публикация не выполнялась. Второй блок [контракта](../next-experiment-statistics-ui.md). Физика, геном, обучение, RNG, повторы и выбор итоговых попыток прежние. Расчётный снимок 0.39.2 не менялся.

## Интерфейс

- Кнопка «Настройки статистики» находится рядом с основными вкладками. Открытая панель занимает левую колонку, сдвигая графики вправо; на узком экране располагается над данными. Управление нажатием, Escape закрывает; наведение ничего не открывает.
- Новый график средней численности: на целой Т берётся N(t); в широком интервале сначала временная средняя каждого мира, затем сводка этих мировых средних с равным весом миров. Минимум/максимум — крайние мировые средние, не погрешность. У одного мира четыре сводки совпадают.
- Чувствительности сравниваются соседними столбиками гистограммы с общими корзинами по 5 процентных пунктов. Цвет варианта постоянен при выборе подмножества вариантов; первый зелёный, второй жёлтый, включая пищу.
- Под графиками — среднее, медиана, приближённые 95% ДИ и число пригодных миров за общий период. Раскрываются значения отдельных миров. Для метрик особей период отбирает рождения, показатели относятся ко всей наблюдаемой жизни; для населения/пищи — время мира. Переключение линии/весов период не сбрасывает.
- По умолчанию доверительная полоса. Отдельно выбираются межквартильный разброс миров (25–75%) или отсутствие полосы. Шкала учитывает границы; пропуски не соединяются. Среднее/медиана получают полосы, экстремумы — нет. Гистограммы и отдельная кривая дожития сохраняют свой смысл: её пунктирные границы цензурирования не являются ДИ.

## Определения и ограничения

Индивидуальные метрики используют прежние lifeMetric и веса. «Особей»: вес строки 1; «Миров»: вес строки 1/n_w пригодных особей её мира для метрики/фильтров. Медиана определяется по накопленному весу индивидуальных значений, не заменяется медианой мировых медиан. Пустой для метрики мир не равен нулю.

Население восстанавливается из рождений/смертей: born ≤ t < endTick, на целых Т. Неполная история не подменяется интерполяцией. После вымирания выбранной попытки население нулевое до планового конца; ручная остановка и ошибка нулями не дополняются. Для пищи/выработки используются только наблюдаемые интервалы каждого мира.

ДИ: **приближённый percentile cluster bootstrap**, 999 воспроизводимых перевыборок доступных миров целиком с пересчётом нужной статистики. Порог показа — пять миров; это интерфейсное ограничение, не гарантия точности. При 5–9 повторах особенно осторожное чтение. Нулевой наблюдаемый разброс не доказывает точность; бутстрэп не создаёт независимых миров. При неполных деталях ДИ отключён с пояснением. Неизвестное дожитие не считается смертью или молча исключённым исходом.

Полосы **поточечные**, не 95% одновременная гарантия для всей траектории. Пересечение полос не является проверкой равенства вариантов. Разброс показывает квартили мировых средних/медиан, ДИ — неопределённость центральной оценки. Разности A/B, отношения, проценты и их интервалы — третий блок, не добавлены. При разных seed выбранных попыток сравниваются настройки вместе с правилом повторов, а не изолированный эффект на одинаковых жителях; вымирания видимы.

[NIST — смысл ДИ](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm), [SciPy — bootstrap и percentile-интервалы](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html). Конкретные 999 повторов, порог пять и UI — решения прототипа, не универсальный научный стандарт.

## Стоимость и данные

`statistical-series.js` готовит видимые показатели; отдельный `statistics-worker.js` получает числовые буферы, не полные отчёты/мозги. Сортировка однократная на задачу; медианы перевыборок используют CDF (не более миллиона ячеек) либо двоичный поиск. Повторяющиеся составы и сами перевыборки переиспользуются. Линия/полоса/размер используют готовый результат; смена данных/периода/фильтра прекращает устаревший Worker. Численные таблицы не перестраиваются при каждом наведении. Извлечение чисел остаётся работой UI с передачей управления между метриками. Население интегрируется по отсортированным событиям без массива всех подшагов. Нулевая стоимость больших историй не обещается.

`json-export.js` фиксирует состав попыток/жизней, переиспользуя неизменяемые строки. JSON собирается порциями около 512 КиБ с передачей управления браузеру, без гигантской строки всего отчёта. Есть прогресс/ошибка, файл выдаётся после успешной сборки. Ссылка прикреплена к документу, Blob URL освобождается через 60 с. Итоговый Blob всё равно требует память; импорт по-прежнему ограничен 256 МиБ.

Полные сохранения той же схемы/биологии из 0.39.2 и 0.40.0 принимаются без преобразования. Несовместимые и неизвестные версии отвергаются.
