# Расшифровка и сравнение геномов — 0.14

Разрешено 2026-10-13. Первый этап F23: геномы и сравнение пары. Истории/испытания
не являются входами анализатора на этом этапе. [Вход](../START_HERE.md),
[текущая модель](../current-model.md), [F23](../archive/context-2026-10-18/future-ideas.md#f23--постоянные-инструменты-расшифровки-данных).

## Пользовательский сценарий

Открыть вкладку «Анализ» (прямая ссылка `?tab=analysis`), загрузить JSON в A.
Можно загрузить только B для одиночного разбора. Второй файл добавляет сравнение
B − A. TXT с тем же JSON также принимается. Максимум 100000 байт на файл.
Неверный файл показывает ошибку своего слота, не меняет другой. Очистка и новая
загрузка отменяют запоздавшие результаты чтения. Файлы не отправляются на сервер,
не становятся основой мира и не сохраняются автоматически между перезагрузками.
Смена вкладки ставит наблюдение на паузу, как история/испытания; разбор не
создаёт мир, не выполняет шаги, не меняет геномы, память, настройки или RNG.

В интерфейсе есть:

- источник файла, схема, число генов, номер особи, поколение, дети при экспорте,
  seed/шаг, модель/шкала, SHA-256 исходных байтов при доступном Web Crypto;
- 22 подписанных общих позиции: движение, ощущения, пространственные склонности,
  память/обучение; отсутствующие свойства старой версии явно помечены;
- оригинальный индекс с нуля, сырое число, пересчитанная вместимость/скорость/
  длительность и подписанная доля шкалы чувств;
- пояснения, ограничения и сохранённые числовые правила/краткая среда из файла;
- сравнение общих свойств, 20 наибольших различий, количество совместных/
  изменённых/имеющихся лишь в одной версии генов;
- 48 строк базовых оценок или разностей B − A, фильтр по условной энергии.

JSON анализа сохраняет все строки, свойства и разности с исходной точностью.
Markdown — короткие пояснения/таблицы, округление только при печати; полная
матрица в JSON. Экспорт отражает оба загруженных файла независимо от фильтра
и выбранного вида. Производный отчёт не является геномом для импорта; оригиналы
хранить отдельно. «—» не равен нулю. Большая разность или память не означает
лучшую стратегию, а базовый вес не равен вероятности выбора.

## Схемы и границы знания

| Геном | Чисел | Столбцов действий | Общие свойства в оригинале |
| --- | ---: | ---: | --- |
| v1 | 435 | 9 | 3 движения |
| v2 | 450 | 9 | 3 движения +15 чувств/обучения/памяти |
| v3 | 454 | 9 | 3 движения +19 свойств |
| v4 | 502 | 10 | Те же 22, добавлено рождение в каждой строке |
| v5 | 550 | 11 | Те же 22, добавлено выкладывание в каждой строке |

Сравнение по строке/номеру действия и ключу свойства, не абсолютному индексу.
Отсутствовавшие свойства не заполняются нулями в выводе. Валидатор импорта
используется для проверки и внутреннего переноса существующих значений к общей
формуле, но исходный файл не изменяется и не становится новым геномом.

brain-parameters.js содержит общую неизменённую шкалу cognition-v1: одна функция
для модели и анализатора. Перенос cognitiveTraits проверен текстовым совпадением
тела функции, без изменения её чисел. При будущей смене шкал сохранять прежнюю
именованную функцию и добавлять новую, не переписывать смысл старых файлов.
Экспорты новых геномов имеют modelVersion и policyContext (кодирование состояний,
шкала, личные направления); формат генома остаётся v5, правила тела прежние.

Старые файлы не указывают полную версию мозга/кодирование/шкалу. В этом случае
в отчёте явно указано использование поддерживаемых соглашений анализатора:
это не восстановление исторического тела и траекторий. Подписи уровней энергии
относятся к соглашению нынешнего табличного мозга (<30, <70, ≥70). Если файл
указывает неизвестное кодирование, показываются номера/веса без состояний,
фильтр энергии выключен, политика не сравнивается по смыслу. Если шкала явно
неизвестна, скорости/вместимости/доли чувств не пересчитываются. Неизвестная
версия генома, неправильный размер/формат/неконечные числа/числа вне −8…8 отвергаются.

Личный опыт, содержимое памяти, возраст/тело, маршруты и полная родословная в
геноме не сохранены. Поколение/дети — контекст момента экспорта, не доказательство
долгой жизни или универсальности. В старых реализациях направления могли быть
мировыми; анализ показывает названия поддерживаемой схемы, не воспроизводит
оригинальный контроллер.

## Повторяемый инструмент

Чистый модуль: dist/genome-analysis.js. Интерфейс: dist/genome-analysis-ui.js.
Для агента/разработчика тот же модуль через Node, без браузера и симуляции:

```bash
node tools/analyze-genomes.mjs file-A.json file-B.json
node tools/analyze-genomes.mjs --markdown file-A.json
```

Результат идёт в stdout, входы/мир не меняются. Пользователю установка Node не
нужна: весь сценарий доступен на сайте. Отчёт big-evolution-genome-analysis v1;
схема модели v5/550, жизни v3 и испытания v4 не менялись.

## Проверка

Подготовлены **82 браузерные проверки**: прежние 74 +8 анализатора. Их запускает
пользователь. Агент не исполнял набор или симуляции. Новые ID:
analysis-schemas, analysis-mixed-versions, analysis-difference-direction,
analysis-scaled-memory, analysis-input-errors, analysis-unknown-convention,
analysis-no-mutation, analysis-export. Проверяют старые схемы/отсутствие,
семантическое сравнение v4/v5, знак B − A, известные 25/54 места, испорченные
входы, неизвестные соглашения, неизменность входов и экспорт одиночного B.

Агент выполнил статический синтаксис/импорты/HTML/ARIA/справку/документы и
пользовательский разбор ранее присланных реальных файлов через CLI: v1 (435) и
v4 (502). v1 имеет лишь три движения, память не приписана; v4 даёт 25/54 места,
совпадая с прежним разбором; SHA-256 v4 совпадает с ранее зафиксированным.
Это чтение JSON, не запуск механических проверок или новых миров. CLI вывел
JSON и Markdown. Клики/отрисовка настоящего браузера не проверены.

Ручная проверка: загрузить один файл в B; убедиться, что отчёт подписан B.
Добавить A, переключить свойства/матрицу, сравнить v4/v5 (отсутствующий столбец
«Положить» не нуль). Скачать оба формата. Загрузить вместо одного файла историю
мира или испорченный JSON — должна быть ошибка своего слота. Очистить слот во
время чтения — старый результат не должен возвращаться. Открыть справку с
клавиатуры и проверить узкий экран. Новые успешные результаты присылает пользователь.
