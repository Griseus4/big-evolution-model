# 0.54.0 — пособие «О проекте», микропатч 1

## Объём и результат

Пользователь поручил первый микропатч после просмотра наброска и добавил краткую выжимку для каждой статьи при наведении на ссылку. [Контракт](../next-game-guide.md). Вкладка переименована в «О проекте»: слева раскрываемое оглавление, справа отдельная статья. На узком экране оглавление располагается над статьёй. Прежние 14 статей остаются доступны в тематических ветках.

Добавлена законченная вводная статья «О проекте и цели модели»: понятное объяснение, пример исследования, раскрываемые точные правила, связанные статьи. Уточнение фразы о наброске: прежний текст был примером подачи; опубликованная статья сверена с кодом наблюдений, наследования, создания личного мозга, оценки чувств и обучения. Цель исследования социального поведения взята из принятого направления проекта, а не выдана за уже реализованное общество.

У всех 15 статей есть выжимки в [едином реестре](../../dist/project-guide.js). Общая подсказка показывает их через 700 мс при наведении или фокусе с клавиатуры. По нажатию открывается статья, подсказка закрывается. У ссылок обычные URL `#wiki-panel-…`: работают прямой вход, переходы из других статей, история браузера и открытие в новой вкладке. Навигация сохраняет DOM, раскрытые правила и положение чтения; не запрашивает паузу мира.

Новые тексты хранятся в одном модуле; прежние пояснения остаются в ui-text. В реестре вводной статьи указаны файлы, символы, связанные статьи и версия содержательной сверки. Прежние статьи имеют reviewedVersion=null: перенос не объявлен полной проверкой всего пособия. Новые главы, поиск и визуальная карта справочника отложены.

## Граница и стоимость

Изменены представление и навигация, не физика, обучение, геном, RNG или формулы статистики. Нет работы на подшаг/особь: реестр содержит 15 записей, выбор статьи обходит их только при навигации; выжимки используют один существующий popover. Расчётный снимок остаётся 0.53.2. Полные миры 0.53.0–0.53.3 принимаются по прежней схеме; результаты опытов читаются прежним импортом.
