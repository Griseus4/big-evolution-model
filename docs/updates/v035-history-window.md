# 0.35.1 — масштаб и период графиков, возрастная кривая дожития

18 октября2026. Пользователь поручил реализовать исправление последнего выпуска графиков. Энергетика, случайная среда, сохранение мира и структурная эволюция не входят в0.35.1. Новая цель будущей среды — расчёт кормовой базы примерно на100…200 особей вместо фиксированных59% богатства.

## Контракт и реализация

- Запас/энергия: нижняя граница0, верхняя по включённым линиям выбранного окна с8% запаса. Отключённый максимум не растягивает ось. Для пустых/нулевых значений ненулевой диапазон; проценты дожития/голода остаются0…100.
- Общая дорожка с двумя нативными круглыми ползунками, точные числовые поля и сброс «Весь период». Период[начало;конец) фильтрует рождения для10 прежних графиков и таблицы; показатели остаются за всю жизнь. Для пищи это то же время мира. Ширина групп настраивается отдельно. Краевые группы/средние пищи считаются по точным границам.
- Одна независимая возрастная кривая: X возраст, Y доля, собственное начало рождения, ширина из общей настройки интервала рождения, фильтр происхождения. Включает живых и умерших независимо от режима индивидуальных четырёх линий.
- Для возрастаA подтверждённая доля = уже достигшиеA / все сохранённые рождения группы. Верхняя возможная доля дополнительно включает живых, которые ещё не достиглиA. При неизвестных исходах показаны пунктир и полоса между границами. Это не модель вероятности и не доверительный интервал; неизвестный живой не считается умершим. При открытом периоде рождения знаменатель ещё меняется, группа отмечена предварительной. При отсутствующих подробностях кривая отключается.
- При полном наблюдении закрытой группы кривая точная и сплошная. Умерший в возрастеA считается дожившим доA; падение происходит со следующего подшага. Для рисунка до512 порогов, точная подсказка произвольного возраста считается независимо от прореживания через двоичный поиск.
- Таблица сохраняет50 строк/страницу, внутреннюю прокрутку, поиск/фильтры, клавиатурный выбор. Общая сводка явно подписана «Весь мир».

## Стоимость и границы

Полные группы/индекс принадлежности строятся при новом отчёте или изменении группировки. Сдвиг периода переиспользует целые группы, пересчитывая максимум две краевые; полная история не сортируется заново. Средние пищи на краях читают префикс в постоянное время. Пагинация/линии/выбор/resize не пересчитывают жизни. Возрастная кривая кешируется отдельно от общего периода, два массива возрастов сортируются один раз и сливаются без третьей сортировки. В мире/сообщениях Worker новых счётчиков и проходов нет.

Модули: `history-window.js`, `survival-curve.js`, `history-charts.js`, `history-ui.js`; фильтр точных границ в `life-cohorts.js`. Модель/геном/обучение/память/RNG не менялись. Расчётный снимок остаётся0.35.0; чистый UI отдельного снимка/колонки производительности не требует. Файл lives остаётсяv4, UI-настройки не изменяют экспортированный исходный отчёт.
