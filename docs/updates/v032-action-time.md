## Реализовано

10 подшагов=1Т. Движение15, сбор5, еда2, ожидание5, выкладывание3, роды20. Результаты завершаются по сроку, обычные расходы распределены по времени. Прерывание сохраняет затраты, продолжение сохраняет прогресс. Пища не резервируется; одновременные претенденты на недостаточное число порций получают случайный порядок.

Наследуемый малый мозг16→4→1 проверяется каждый подшаг продолжающегося прерываемого процесса. Он запрашивает основной мозг, который учитывает текущий процесс и может продолжить его. Физический срыв/окончание вызывает основной мозг напрямую. Роды блокируют другие действия и добровольный пересмотр. Лимит населения проверяется в начале родов, уже начатые могут завершиться сверх него. Смерть до окончания исключает потомка.

Выбор стоит0,10; плановый повтор0,03, направление движения сравнивается в личных координатах. Боль/риск/травмы местности удалены. Память наблюдает факты каждый подшаг с весом времени. Обучение по следующему выбору живой особи использует временные награду/дисконт/след/забывание, без финального обучения умершего.

Геномv12:1376 параметров основного мозга+12 свойств+73 внимания+2 мутаций=1463. Старые основы не преобразуются. Новые испытания не предлагают автоматического рождения — отдельное решение пользователя. [Полный контракт](../action-time-spec.md), [действующая модель](../mechanics-reference.md).

## Стоимость реализации

Выбраны фиксированные фазы без очереди событий: при10 подшагах и проверке внимания каждый подшаг очередь не убирает обязательный обход живых. Один проход физиологии, список готовых действий, локальные группы конкуренции и один проход восприятия/выбора. Геометрия семи видимых клеток обновляется только после перемещения, текущие количества читаются один раз на временную границу. Группы сборщиков и буферы внимания переиспользуются. Подготовка входов основного мозга общая для ожидаемой оценки до обучения и выбора после него; действующие веса перечитываются. Личная награда накапливается в двух числах, без ленты подшагов. Забывание личных весов вычисляется при основном выборе. Малый мозг не выполняет обучение и RNG.

Проверка внимания сама по себе лёгкая, но частые положительные запросы увеличивают число полных выборов/обучений. Выпуск меняет модель и не обещает ускорения относительно0.31 или1280Т/с. Очевидные повторные аллокации устранены, абсолютный оптимум не заявляется.
