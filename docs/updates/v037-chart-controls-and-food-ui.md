# 0.37.2 — выдвижные настройки статистики и читаемые пищевые условия

## Уточнённый контракт интерфейса

Пользователь заменил предложение закреплённой полосы двумя скрываемыми панелями: **сверху** линии индивидуальных показателей, общий период и выбор графиков; **слева** интервал рождения, возраст дожития, происхождение, режим данных и прерывания. Панели доступны при прокрутке и открываются наведением. Нативный `details` также поддерживает нажатие, Enter и Space; Escape закрывает панель с возвратом фокуса на её заголовок. Уход мыши не закрывает панель, пока внутри редактируется поле. Фокус после подсказки возвращается к доступному полю. Это заменяет постоянно видимые переключатели0.37.1; выбранный максимум оси дожития сохранён.

`history-drawers.js` управляет только событиями границы/фокуса. Нет обработчика прокрутки и вычислений на каждом кадре. CSS закрепляет верхний заголовок под фактической высотой навигации, левый — у края экрана; на узком экране учитывается незакреплённая навигация. Открытые панели перекрывают страницу и имеют собственную прокрутку без сдвига графиков. Все настройки — прежние DOM-элементы, смена состояния панелей их не пересоздаёт.

Выбор графиков развёрнут в колонки: выживание, поведение, ресурсы, размножение, наследуемые свойства, распределения. У каждой колонки заголовок и чекбоксы; узкий экран переносит колонки в несколько рядов. Единый список групп определяет и эти колонки, и готовые экраны. По последнему уточнению пользователя все три линейных графика чувствительности (энергия, здоровье, наполнение желудка) исключены из создания и выбора. Три распределения, генетические данные/экспорт и показатели таблицы сохранены. Остальные наследуемые свойства по-прежнему имеют линейные графики.

У трёх распределений подписи осиX:−100,−80,…,0,…,80,100. Меняется только сетка подписей; ширина интервалов5 процентных пунктов и сами распределения прежние.

## Пищевые числа и версия

В «Мир → Источники пищи → Условия» добавлена **ожидаемая выработка действующего мира**, по точным календарям источников. Она берётся из уже переданной сводки, пересчитывать карту в интерфейсе не требуется. Пояснение различает потенциальный рост и фактический: полные источники пропускают рост; ещё не применённые ручные поля не меняют показанную выработку.

`ui-numbers.js` задаёт округление подписей и числового представления до десятых: периоды/шаги, проценты, выработка и прочие дробные пищевые величины. Подписи используют русскую запись, поля — числовую запись с точкой. Отрицательный ноль и двоичные хвосты не показываются. Точные значения остаются в исходных ползунках/состоянии; `readFoodControls` читает их, поэтому применение неизменённых округлённых полей не меняет среду. Активный числовой ввод не перезаписывается; после ухода фокуса отображение округляется. Осознанный ввод нового числа применяет именно введённое число, без снижения точности модели.

Подвал показывает только `Версия` и автоматический `APP_VERSION` из общего источника, как заголовок. Ручного номера в HTML нет. Новый выпуск0.37.2, принимаются сохранения0.37.1/0.37.0; расчётный снимок испытаний0.37.0 прежний. Физика, геном, RNG, обучение, сама чувствительность и правила автоматики не менялись.
