# 0.47.0 — конструктор анализа опыта

Пользователь разрешил реализовать согласованный конструктор и подготовить инструкцию; отдельную реорганизацию вкладок оставил на будущее. Один опыт, выбранные итоговые попытки, без изменения физики/обучения/RNG и без нового расчётного снимка.

## Возможность

В статистике добавлены кнопка/экран конструктора. Группы/дополнительное разбиение и фильтры выбираются по факторам опыта, геномы представлены категориями, исходные варианты доступны отдельно. Выражение и условие задаются поверх числовых полей жизней; агрегаты — среднее, медиана, доля, среднее мировых количеств/сумм. Ось X — период рождения, фактор или номер ребёнка. `birthAge(n)` восстанавливает N-е рождение через связи родителей/детей; `N` на соответствующей оси параметризует один рецепт. Линии, столбцы и таблица; состав ячейки раскрывается. [Пользовательская инструкция](../analysis-builder-guide.md).

Определения сохраняются в localStorage (до 50), импорт/экспорт — `big-evolution-analysis-template`, версия 1. Форматы планов, генома, миров и результатов опытов не менялись. Полные старые истории с нужными связями пригодны; отсутствующие поля/события не восстанавливаются нулями.

## Расчёты и стоимость

`analysis-expression.js` — ограниченный разбор выражений без eval; глубина/размер ограничены, поля из каталога, отсутствующие данные/нуль в знаменателе дают пропуск. `analysis-builder-core.js` — схема, компактный план, группировка и оценки. `analysis-projection.js` читает архив блоками, не меняя обычное загруженное окно; в Worker передаёт только используемые числовые столбцы. Для рождений добавляется компактная полная связь ID/родитель/время/число детей; её индекс строится один раз на мир и расчёт, не на каждую особь/номер. При неполной истории порядок не выдумывается.

Отдельный Worker принимает миры последовательно с подтверждением, чтобы не копить очередь больших буферов. Формулы считаются на особь, оценки — по выбранным весам. Внутри точки исключаются исходные повторы с неполным набором выбранных вариантов/метрики; состав показывается. 999 совместных перевыборок целого исходного повтора, минимум пять полных повторов; используется общий движок мировых оценок. Медиана не заменяется медианой мировых медиан. Количества/суммы сначала дают одно значение на мир, затем среднее с равными весами. Объединённые группы не добавляют независимых повторов.

Расчёт только по кнопке; отмена завершает Worker, устаревший ответ не заменяет источник. Готовая оценка переиспользуется при изменении только названия/вида и на resize. Средние считают мировые суммы/числа без сортировки и CDF медианы; индекс событий оставляет данные только выбранных родителей. До 400 временных точек/600 ячеек, ось номеров детей до 20, отдельный `birthAge(n)` до 1000. На физический подшаг и особь модель не получает новых операций. Скорость/пиковая память на пользовательском большом архиве не измерялись; для N-го рождения нужно больше блоков, чем для обычного окна.
