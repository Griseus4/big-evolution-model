## Что измеряется

[performance-probe.js](../../dist/performance-probe.js) содержит необязательный синхронный контекст выбранного шага. [PerformanceProfiler](../../dist/performance-profiler.js) включает его только на каждом десятом шаге и восстанавливает через finally. Метки не принадлежат мозгу/геному, UI-оценки и другие задачи вне шага их не включают. Выключенная запись не создаёт меток и не вызывает таймеров, но дополнительные проверки/вызовы пустых hooks остаются в коде.

| Этап | Граница |
| --- | --- |
| observation | decisionFrame: сведения и физически доступные варианты |
| inputs | prepareSetInput/setCandidateInput: тело, память, признаки и входные массивы |
| weights | effective: действующие наследуемые веса с личными поправками |
| forward | Общий/кандидатный прямой проход, критерии операций и Q |
| probabilities | Нормировка вероятностей операций/целей |
| gradient | Обратный проход setGradient, без отдельно учтённых прямых проходов |
| updates | Норма, TD-ошибка, след и обновление личных весов |
| copies | Массивы/объекты вариантов, запись последнего решения и pending-входов |
| afterUpdate | Повторная проверка Q после обучения: residual и inclusiveMs целиком |

Метки стоят на границах этапов, не внутри циклов нейронов/975 параметров. Полные участки находятся в set-brain.js, set-brain-inputs.js, brain-controller.js и Evolution.choose. Арифметические выражения, порядок суммирования, владение историческими входами и частота обучения сохранены.

## Учёт и показ

Общие группы evaluation/learning/selection/worldOther сохраняют полное прежнее время. Отдельный стек хранит detailGroups[parent][phase]: **ms** без вложенных этапов, **inclusiveMs** с ними и calls. Поэтому числовой forward внутри градиента не считается дважды. details содержит totalMs родителя, coveredMs, остаток unattributedMs и доли фаз shareOfParent. Родитель и дочерние этапы не складываются. Повторная проверка afterUpdate отдельно показывает inclusiveMs, чтобы был виден её полный расход вместе с forward/weights.

[Панель](../../dist/performance-ui.js) показывает оба уровня, остаток и пояснение. [WorldProfiler](../../dist/world-profiler.js) переносит эти данные из Worker и отдельно добавляет UI; совместимость с отсутствующей детализациейv1 проверена. JSON скачивается той же кнопкой «Скачать измерения».

Это интервалы elapsed JS, включая возможную GC/вытеснение, не CPU%, не объём аллокаций и не время GC отдельно. Например, массивы, создаваемые внутри числового forward, относятся к forward; отдельные copies охватывают явно выделенные копии/данные решений. Эти измерения ещё не доказывают долю арифметики, которую ускорит WASM.
