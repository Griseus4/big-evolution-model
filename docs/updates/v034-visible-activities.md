# 0.34.0 — видимость деятельности других

## Разрешённый результат

Пользователь выбрал более детальный вариант наблюдения: все виды текущих действий на своей и соседних клетках. Это изменение модели для исследования реакций на других, не обещание появления стаи или ускорения. Социальная память и новые действия не добавлены. Физиология, длительности, цены мышления/действий и обучение по последствиям остаются прежними.

На каждую из максимум7 видимых клеток:6 количеств движения по направлениям относительно наблюдателя, подбор, еда, ожидание, роды, выкладывание. Отдельные количества сохраняют встречные потоки. Свой вклад исключён; чужие ID не входят в сеть. Прогресс, оставшееся время, скрытые запасы/здоровье/намерения не передаются. Особь без активного процесса входит только в общую численность.

## Порядок и владельцы

Общая физика завершает интервал; завершения и невозможные действия обрабатываются до общего снимка. `prepareTemporalBoundary` фиксирует деятельность перед всеми новыми решениями. Текущие решения проявляются в следующем подшаге. Однопоточный и параллельный пути используют одну границу независимо от порядка ответов Worker. Движение видно на исходном гексе до завершения; прерывание не выдаётся за успешный переход.

`activity-perception.js` принадлежит координатору: переиспользуемый Int32-массив11 счётчиков/клетку и список занятых строк для очистки. Один проход по живым без попарного сравнения. В личных семи строках переиспользуются Float64-счётчики с преобразованием направлений и исключением себя. `cognition-packet` протокол2 переносит исходные количества без округления. Мозг не получает общую карту.

Малая сеть получает один дополнительный признак изменения деятельности с последнего основного выбора. Это обучаемый через поколения сигнал, не обязательный пересмотр. В пространственную память действия других не записываются. Личный снимок внимания не наследуется.

## Численная схема и стоимость

Геномv13, тип set-duration-activity-v1:1918 чисел =1827 весов основного мозга +12 свойств +77 параметров малого мозга +2 регулятора. Клетки21→8; контекст65→16; цели28→16; малая сеть17→4→1. Основной мозг видит деятельность в клетках, цели кандидата и цели собственного процесса. Новых выходов нет. v12 явно отклоняется, преобразование не поддерживается.

По сравнению с0.33.2: +451 параметр основного мозга, +4 малого, +77 Float64 в пакете одной особи (616байт/подшаг при7 клетках), +77 чисел краткого снимка внимания. Передаваемые буферы возвращаются владельцу, списки отдельных соседей не создаются. Новые веса и реакции могут менять частоту решений: низкую стоимость сбора сведений нельзя выдавать за гарантированно малое изменение общего времени мира.

Новая серия duration-activity-v1, нагрузки fixed-activity-workloads-v1, первый неизменяемый снимок0.34.0 из commit0de95f7 (42 модуля). Число вычислителей сравнивается на одинаковом состоянии этой модели. Старые отчётыv1–v5 читаются отдельно; прежние снимки сохранены на диске и в Git, но исключены из выбора новых замеров. Автоматическая проверка отклонила широкое удаление четырёх исторических каталогов; удаления не было, при обычной работе они не импортируются. Между моделями совпадение траекторий не требуется, процент чистой оптимизации не выводится.
