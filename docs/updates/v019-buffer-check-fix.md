# 0.19.1 — исправление проверки независимости буферов

2026-10-13. Пользователь прислал big-evolution-tests-2026-10-13T17-32-08-362Z.json: модель 0.19.0, format big-evolution-tests v4, полный список 120 уникальных ID, 119 passed / 1 failed. Отпечаток совпадает с опубликованной 0.19. Единственная ошибка optimization-buffer-isolation: «Устаревшие эффективные веса».

## Причина

Ошибка в тесте: actual = world.evaluate(a) уже содержит destination с мировыми координатами исполнения. expected = probabilities(referenceEvaluate(...)) содержит ответ мозга без destination. JSON полного варианта не может совпасть даже при идентичных Q/входах/вероятностях. Проверка падала после уже успешных утверждений о неизменности старых вариантов и независимости входов/senses. Следующая проверка переключения TD имела тот же неправильный уровень сравнения, но до неё исполнение ещё не дошло.

0.19.1 добавляет referenceWorldOptions: замороженный мозг 0.18 оценивает чистый request, затем world.executableDecision добавляет координаты исполнения, как в actual. Исправлены обе ожидаемые стороны. Полное сравнение остаётся точным; числовые поля/массивы не исключаются, допуск не увеличен.

Мировые координаты по-прежнему добавляет только исполнитель после ответа мозга. Никаких новых данных сеть не получает. Производственные neural-brain, brain-controller, Evolution и физика не изменены. Номер версии/описание/экспорт исходников обновлены. Это исправление проверочной фикстуры, не откат оптимизации.

Это ограниченная регрессионная проверка, не доказательство всех возможных миров или ускорения. Исторические 96 и сетевые 14 также успешны.
