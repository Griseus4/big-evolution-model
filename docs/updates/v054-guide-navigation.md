# 0.54.1 — пособие, микропатч 2: поиск и реализация

## Результат

По явному поручению продолжен [план пособия](../next-game-guide.md). Поиск в левой части «О проекте» сопоставляет все слова запроса с названиями, выжимками, терминами, файлами и функциями. Регистр и ё/е не различаются; регулярные выражения из ввода не исполняются. Enter открывает первый результат, Escape возвращает дерево. Сам ввод не переключает статью и не меняет мир или фильтры статистики.

У всех 15 статей есть раскрываемый блок «Где это в коде»: исходники, символы, краткое назначение и связанные проверки. Он создаётся один раз при первом открытии статьи. Указатели для прежних статей добавлены как средство навигации, не как заявление об их полной содержательной сверке. Вводная статья обновлена инструкцией поиска/источников и сведениями об устройстве пособия; версия её сверки — 0.54.1.

«Полнота описания» загружает инвентарь только при раскрытии. На этом этапе в нём 271 файл: 191 рабочий исходник, 59 проверок, 18 инструментов, 2 файла инфраструктуры и 1 исторический экран. Видны файлы без статей и имеющиеся указатели. Ссылки в статьях — не процент описания кода; содержательно сверена одна вводная статья из 15. Производные копии, документы и неизменяемые снимки исключены из этого инвентаря. Полного семантического аудита всех файлов в этом микропатче нет.

Страница исходников больше не показывает версию 0.5.1 и описание старого табличного мозга как текущего. Версия берётся из app-version, вход по умолчанию — START_HERE; ссылки продолжают выбирать файл только из манифеста, без загрузки произвольного URL.

## Устройство и стоимость

- Реестр — [project-guide.js](../../dist/project-guide.js); термины/указатели — [project-guide-topics.js](../../dist/project-guide-topics.js). Поиск/подсчёт ссылок — [project-guide-search.js](../../dist/project-guide-search.js).
- Представление источников и ленивая загрузка — [project-guide-sources-ui.js](../../dist/project-guide-sources-ui.js). Запросы объединяются; результат кэшируется, после ошибки можно повторить раскрытием. Список другой версии/формата отвергается.
- Инвентарь формирует [guide_inventory.py](../../tools/guide_inventory.py) только через экспортёр. Документальная проверка сопоставляет его с текущими рабочими файлами, проверяет файлы/символы/связи статей. Проверки тестов/инструментов рекурсивны; снимки и source-files не включаются повторно.
- На подшаг и особь работы нет. Поиск просматривает 15 коротких записей только при вводе; технический блок строится один раз на статью; список исходников — один раз после раскрытия. Ускорение не измерялось.

Игровые формулы, структура генома и RNG не менялись; расчётный снимок остаётся 0.53.2. Читаются полные миры 0.53.0–0.54.0 по прежней схеме.
