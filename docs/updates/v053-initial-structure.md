# 0.53.2 — начальная структура мозга и заполнение схемы

Статус: реализовано по явному поручению после подтверждения таблицы, процентов и пустых слоёв. Пользователь также поручил увеличить схему в миниатюре и отдать ей около 75% ширины полноэкранного просмотра. [Предыдущая механика](v053-structural-brain.md), [управление схемой](v053-brain-viewer.md).

## Настройка и инструкция

Обычный мир: «Мир → Стартовые условия → Прочее». Опыт: «Настройка опыта → Общие условия мира → Мозг». Сначала укажите пределы скрытых нейронов и слоёв, затем заполните горизонтальную таблицу «Слой / Нейроны». Сумма разрешена до предела включительно, число непустых слоёв — до предела слоёв. Пустые столбцы пропускаются: `5, 0, 3, 0` создаёт два слоя 5→3. Все нули означают отсутствие скрытых слоёв. Пределы допускают 0, верхние технические ограничения остаются 256 нейронов / 16 слоёв; заводские пределы 64 / 4.

Заводская таблица — `5, 0, 0, 0`, связность 100%. Настройки относятся только к изменяемому главному контексту, не ко всем частям мозга. В опыте «Начальные нейроны по слоям» и «Начальная связность, %» доступны также как изменяемые параметры; каждое значение первого фактора — отдельная таблица. Пример сравнения: таблицы 5 и 3→2, связность 50 и 100 дают четыре варианта. Пределы общего набора должны вмещать все выбранные структуры.

## Значение связности

Пусть размеры непустых уровней — входы, скрытые слои, выходы. Базовое число B — сумма произведений размеров соседних уровней; максимум M — сумма произведений размеров всех пар уровней, упорядоченных вперёд. Начальное число связей E = round(B × процент / 100), с верхним ограничением M. В форме видны количество связей и доступный максимум процента 100M/B.

- 0%: никаких связей изменяемого блока, фиксированные части мозга сохраняются.
- Ниже 100%: равномерный выбор ровно E различных соседних связей, без требования связности всех нейронов.
- 100%: все связи между соседними непустыми уровнями.
- Выше 100%: все соседние связи плюс ровно E−B случайных связей с пропусками уровней, включая вход→выход. Циклов, обратных связей и повторов нет.
- Без скрытых слоёв входы и выходы соседние: максимум 100%.

Количество у всех случайных основателей одинаково; выбранные связи и веса случайны, задаются seed жителей. Для начальных рёбер используется отдельный поток с одним seed на основателя: смена таблицы/процента не сдвигает остальные гены, размещение и случайность следующих основателей. Процент не является вероятностью независимого броска на каждую связь. Случайные веса симметричны относительно нуля и масштабируются размерами соединяемых уровней; нулевой исходящий вес при добавлении нейрона потомку остаётся прежним правилом 0.53.

Основатели из файла сохраняют структуру загруженного генома; начальные таблица/процент для них не применяются, поля отключаются с пояснением. Геном всё равно должен вписываться в технические пределы мира. Дети наследуют схему с прежними мутациями, не сбрасываются к стартовой таблице. Обучение изменяет существующие веса, не создаёт отсутствующие связи.

## Схема и границы

Миниатюра и полноэкранное полотно раскладывают те же узлы под свои пропорции: расстояния меняются, круги не растягиваются. На ПК полотно получает примерно 75% ширины, пояснения — оставшуюся часть; на узком экране они расположены друг над другом. Вся схема видна при открытии, далее действуют колесо, перетаскивание ЛКМ и выбор элементов. Геометрия просмотра не выполняет расчёт мозга и не расходует RNG.

## Файлы, совместимость и стоимость

[brain-initialization.js](../../dist/brain-initialization.js) задаёт проверку/число связей/выбор; [brain-initialization-ui.js](../../dist/brain-initialization-ui.js) — общую форму. Генератор вызывается только при создании случайного основателя из [structural-brain.js](../../dist/structural-brain.js). На подшаг новая настройка не добавляет работы. Выбор без матрицы всех рёбер использует память по числу выбранных связей; обход допустимых пар выполняется только при начальной генерации. Плотный большой геном закономерно требует больше памяти/вычислений.

`initialNeurons` / `initialConnections` сохраняются в настройках плана и полном мире. Геномы остаются v14, полный мир — формат 3; миры 0.53.0/0.53.1 читаются. Результаты прежних опытов читаются историческим валидатором. В отсутствие новых настроек программный API сохраняет случайный старт 4–6 и прежний порядок RNG, в пределах заданных технических максимумов. Это совместимость API, не значение заводской таблицы.

Новый неизменяемый расчётный снимок 0.53.2 создаётся из исходного commit при упаковке. Серия `structural-brain-v1` и набор `structural-brain-workloads-v1` сохраняются: стандартные нагрузки API не изменены, текущим ID расчёта становится 0.53.2. Снимок 0.53.0 не изменяется. Новые времена замеров не заявляются.

## Проверки

Девять новых коротких проверок: пределы/пустые слои, точное число рёбер и уникальность/направление, все основатели/seed, изоляция прочих генов/RNG, нулевая глубина/мутации, сохранение/геном из файла, Workers с обучением, факторы/фильтры/план, заполнение обзора по обеим осям. Два новых сценария настоящего конструктора в минимальном DOM проверяют отправку настроек и добавление таблиц фактора. Существующие тесты схемы, геномов/ощущений, конструктора, группировки, сохранений, параллельного исполнения и UI выполнены; устаревшие ожидания схемы до 0.53 заменены проверкой действующей совместимости. Полный набор и длительные опыты не запускались. Последний прогон после разделения RNG: 47 проверок схемы, структуры, сохранений и UI мира прошли; неизменённые проверки конструктора/анализа/параллельности ранее прошли после исправления стендов. DOM/импорты/синтаксис и документы проверены. Разовая предварительная оценка 1000 основателей с таблицей 2→3: создание около 190–196 мс, один шаг 721–732 мс на этой машине; это не серия и не сравнение ускорения, до заключительного разделения потока рёбер, поэтому не характеристика финальной скорости.

Настоящая браузерная отрисовка в этом патче не проверялась; геометрические и DOM-проверки не доказывают визуальную приёмку Chrome. Дополнительные проверки ради публикации не запускаются.
