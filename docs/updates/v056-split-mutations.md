# 0.56.0 — раздельные мутации весов и структуры

Контекст ситуации и малый мозг могут независимо менять численные параметры и устройство сети. Для каждого типа изменений у каждой сети своя наследуемая вероятность, сила и переключатель. Начальные значения задаются в отдельных строках стартовых условий и конструктора опыта; там же доступны подсказки. Остальные пять групп сохраняют по одной паре. Новый геном v17 содержит девять пар / восемнадцать регуляторов.

## Правила

Вероятность весовой мутации проверяется для каждого веса и смещения, структурной — для события сети. Структурная сила задаёт бюджет нейронов/связей; весовая — численный сдвиг. События независимы и могут совпадать. Сохранившиеся параметры структурная мутация численно не меняет; удаление элемента удаляет его параметры. Новые узлы получают ненулевой вход и нулевой выход по прежним правилам.

Каждая пара самоэволюционирует по своим родительским значениям. Для новых пар действуют прежние случайные стартовые диапазоны, а не потолки эволюции. Общий флаг мутаций запрещает все изменения; общий флаг структуры — только перестройку. Личное обучение основного мозга, вычислительные ставки и калькулятор энергии остаются прежними. Добавленные регуляторы используются при рождении, не добавляют операций в выбор и обучение.

## Совместимость

- Новые миры и планы принимают основы v17. Полные миры v15/v16 продолжают прежние правила без преобразования генов.
- Общие старые регуляторы имеют прежние идентификаторы статистики. Раздельные показатели v17 получают новые; отсутствие показателя не считается нулём. Исторические факторы читаются в режиме результатов, но не запускаются молча под новым смыслом.
- Прежняя сохранённая форма копирует общий профиль в две независимые стартовые пары с уведомлением. Исходный набор остаётся в браузерном ключе с суффиксом `-before-v17`. Старый базовый геном не конвертируется; для новой формы нужно выбрать основу v17 либо сбросить её.
- Серия скорости — `split-mutation-v1`; старые снимки неизменяемы. Прирост приспособленности и долгосрочная эволюция не измерены.

## Пособие и проверки

Главы генома и эволюции структуры сверены с кодом; таблица групп и подсказки используют общий словарь. Числа берутся из владельцев правил. [Контракт](../next-rest-attention.md#обсуждение-после-0554-веса-и-структура).

Итоговый прогон — в [контрольной записи](../work/current.md). Специальные проверки охватывают независимость двух типов, рост с замороженными весами, старый RNG, полное продолжение v16, исторические показатели/факторы и миграцию формы. Настоящая браузерная отрисовка и длительные опыты не проверены.
