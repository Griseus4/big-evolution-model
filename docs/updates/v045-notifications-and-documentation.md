## Изменения

- Начало/окончание опытов показывается только существующим модальным уведомлением. Постоянный баннер после основной панели удалён вместе с его CSS; подтверждение уведомления по-прежнему не управляет паузой. Сообщение о сохранении шаблона остаётся в локальном поле конструктора.
- Восстановлены повреждённые строки START_HERE, verification и протокола архива. Старые планы/результаты сохранены в [истории производительности](../archive/performance-plan-before-2026-10-20.md) и [проверок](../archive/verification-before-2026-10-20.md), относительные ссылки перенаправлены. Текущие маршруты сокращены; расчётная база сверена с benchmark-versions/fixtures. Исправлены устаревшие статусы выполненных контрактов.
- [Правила поддержки](../workflows/context.md) определяют основное место каждого вида сведений и действие после каждого содержательного сообщения/изменения. AGENTS делает их обязательными; благодарности и ответы без новых долговременных сведений не создают записи. Сохраняется различие предложения, согласованного контракта, разрешения и выполненного результата.
- Проверка документов отклоняет символ замены и цепочки из четырёх знаков вопроса. Смысл, авторизацию и истинность результата по-прежнему проверяет агент; автоматический guard этого не доказывает.
