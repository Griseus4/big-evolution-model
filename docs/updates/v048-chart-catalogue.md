# 0.48.0 — единый каталог графиков и общая группировка

Поручение пользователя: перенести прежние графики в общий каталог с конструктором, сохранив категории; разрешить скрывать/копировать стандартные и создавать собственные категории. [Контракт](../next-experiment-statistics-ui.md), [инструкция](../analysis-builder-guide.md).

## Результат

Стандартные метрики, временные ряды населения/пищи/выработки, дожитие и распределения теперь описаны в `chart-catalogue.js`. Редактор создаёт встроенную копию либо формулу; карточка размещается в общей категории. Есть скрытие, восстановление стандартных, редактирование/удаление пользовательских, хранение в браузере и JSON-каталог без историй миров. Прежние шаблоны формул 0.47 переносятся.

Общие группы/дополнительное разбиение и фильтры факторов в панели действуют на прежние графики и формулы. Сохраняются текущий мир, периоды/веса, специализированные семантики дожития, гистограммы, исходные линии и общая пара/B−A у временных встроенных карточек. Период при смене группировки сохраняется. Настройки возрастной кривой доступны в панели, даже когда исходная карточка скрыта.

Похожие уровни настроек не становятся независимыми повторами. В группе с несколькими вариантами ДИ и парное сравнение перевыбирают целиком исходный повтор; неполный состав исключается по показателю/точке и раскрывается. Таблица A/B перечисляет входящие миры с seed, попыткой и вымираниями. Гистограммы/возрастные кривые используют группы с полными по наличию отчётов повторами.

## Стоимость

Расчёта на подшаг/особь в симуляции не добавлено. Данные миров и формат результатов не меняются. Каталог хранит определения без копий историй. Встроенные показатели дедуплицируются перед Worker, поэтому копия графика не создаёт второго статистического задания. Видимые формулы используют общий набор полей, одну проекцию каждого мира, один Worker и подтверждение блока перед следующим. Старые задания отменяются; численные ответы используются при перерисовке. Обработчики не выполняют проходов по карте.

## Проверки и ограничения

Первый связанный прогон: **95/95** коротких Node-проверок (каталог 0.48, анализ 0.47, history UI, statistical UI 0.41, пара 0.42, разности 0.43, experiment UI/statistics, окна/когорты, парсер JS). Проверены реальные Workers, передача числовых буферов, группировки 2×3, пять исходных блоков вместо 15 независимых миров, пропуски, прежние оценки, копия/скрытие/категория/хранилище. Последующие адресные проверки записываются ниже.

После адресных правок: **23/23** (history UI + каталог), **12/12** (experiment UI), **8/8** (каталог/группы/пакетный Worker, включая независимость ошибки одной формулы). Дополнительно проверены копии настроек дожития, формула в общей сетке, сохранение периода при группировке, пустые фильтры, уникальность вложенных передаваемых буферов и медиана блока. Это повторные адресные запуски, их количества не суммируются как уникальные тесты. Документы/бюджеты контекста/diff прошли; browser-wiring статически разобрал 862 JS-файла и 455 HTML ID, 44 браузерные проверки подготовлены, не запущены.

Визуальная проверка настоящего браузера и испытание большого пользовательского архива не выполнялись; ускорение не измерено. Это функциональная организация статистики, физика/обучение/RNG мира не изменялись. Разности произвольных формул, возрастных кривых и гистограмм остаются отдельным будущим этапом. Главные вкладки не реорганизованы.
