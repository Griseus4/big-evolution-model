## Группы и повторы

Оценщики и миры включаются независимыми галочками; обе по умолчанию. Каждая группа имеет собственное число повторов 1…100: 50 оценщикам, 15 мирам. Выключенное поле disabled, его невалидное/пустое значение не мешает другой группе. Без выбранных групп/версий запуск отклоняется с пояснением.

Нагрузки прежние: 3 оценщика ×4096 пакетов, 3 мира ×64 шага. Пакеты, прогрев и computeMs/wallMs прежние. Выбранные версии последовательно чередуются; позиция нагрузки для ротации берётся в полном наборе из шести. Выключение оценщиков не сдвигает ротацию миров. Один Worker, снимки лениво импортируются; только одна версия считает одновременно.

Таблица разделена строками «Оценка действий» и «Полные миры», выключенная группа отсутствует. У каждой строки свой знаменатель повторов. Прогресс показывает завершённые/плановые повторы, номер нагрузки и повтор/число для текущей группы. Процент — доля повторов, не прогноз оставшегося времени: мир и оценщик сильно отличаются по длительности. По умолчанию все 3 версии дают 585 измеренных повторов (3×50×3 + 3×15×3); прогревы не входят в число.

## Случайный номер опыта

🔀 возле поля «Номер опыта» меняет только это поле. До явного «Начать новый опыт» симуляция, её RNG, память, пауза и выбранный житель не меняются. Источник — crypto.getRandomValues браузера, без фиксированной последовательности от seed мира. Выбирается целое 1…4294967295, исключается текущий номер в поле. Глобальная уникальность номеров не обещана. Отбрасывание 0/прежнего номера — равномерный выбор из допустимых значений; аварийный предел 32 попытки исключает зависание при сломанном источнике. Подсказка объясняет применение после перезапуска.

## Пользовательский протокол

1. Ctrl+F5. Убедиться в работе карты/кнопок. Нажать 🔀: номер меняется, мир продолжает прежнюю историю; затем запустить новый опыт и проверить выбранный seed.
2. Запустить 143 механизма и скачать общий JSON. Сообщение 138/138 не заменяет результат нового выпуска.
3. Для короткой ручной проверки выбрать один снимок и только оценщики ×1; проверить одиночную таблицу. Снять обе галочки групп — должно быть пояснение, не запуск.
4. Основное сравнение: версии 0.20, 0.22, 0.24; оценщики ×50, миры ×15, обе группы. Тот же ПК/браузер, вкладка на переднем плане, без тяжёлой фоновой нагрузки. Скачай весь отчёт с механизмами и замерами. Не сравнивать скорость по неравным итоговым SHA.
5. Проверить остановку/повторный запуск и восстановление частичного отчёта после обновления страницы на отдельном пробном запуске. Не прерывать основной эталонный замер.
6. Прислать JSON. Если регресс оценщика сохраняется — следующий отдельный блок измеряет подготовку входов/проход сети/вероятности; не менять поведение ради скорости без решения.
