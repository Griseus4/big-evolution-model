# 0.51.0 — исправления интерфейса и подготовка статистики

## Изменения

- Подсказки появляются через 700 мс при наведении/фокусе; уход отменяет ожидание. Касание/нажатие/Enter открывают сразу, отпускание касания не закрывает справку. Оставшийся «?» у B−A заменён подписью.
- Пять карточек настройки занимают два ряда с равной высотой внутри ряда. Общие условия больше не полагаются на табличный расчёт ширины: поля и длинные подписи переносятся внутри блока; числовой ввод длительности расширен.
- Причина прерываний и возраст дожития, включая копии графиков, размещены перед Canvas и отделены от полей отступом. Кнопки создания/выгрузки графиков перенесены в строку категорий, наблюдение на широком экране центрировано. Проверки механизмов и скорость доступны непосредственными вкладками.
- История популяции использует фактический CSS-размер и DPR; подписи получили внутренние поля. Сведения о мире открываются отдельной кнопкой, пояснение наблюдения перенесено в «Об игре». Сводка условий вычисляется только при открытом окне условий, а не скрытой на каждом обновлении.
- Верхняя статистика сокращена: методические пояснения раскрываются отдельно, предупреждения о неполных данных сохранены. Таблица вымираний показывает оба согласованных отношения по вариантам; ошибки/остановки и отсутствующие флаги исхода не считаются успешным выживанием.
- Успешные сообщения сохранения/выгрузки скрываются через 3 с; ошибки не скрываются. Формат выгрузки выровнен с соседними действиями.

## Расчёты и стоимость

Готовые ответы численной статистики, B−A/таблицы пары и формул сохраняются между вкладками. Ключ включает данные, веса, период и настройки; при изменении контекста старый ответ не подставляется. Для неизменного архива расширение прочитанного окна использует стабильный идентификатор исходного отчёта, сохраняя правильные ранее рассчитанные значения. Закреплённые периоды загружаются до фоновой подготовки.

Сначала готовятся графики выбранной категории, затем один очередной график из остальных. Предварительная подготовка разрешена только для завершённых опытов и мира на паузе; после посещения статистики может продолжиться при переходе в другой раздел. Во время моделирования готовится запрошенная категория. Смена параметров/данных отменяет устаревшую очередь, запуск моделирования прерывает скрытую подготовку. Скрытые Canvas не рисуются.

Кэш прежних ответов — LRU, до 128 ответов/50 000 точек у численных клиентов, 100/50 000 у формул; один ответ сверх лимита точек допускается, текущие отображаемые ответы также остаются доступны. Истории особей в этот кэш не копируются. Каждый численный Worker получает следующую проекцию после ответа на предыдущую, ограничивая очередь переданных массивов. Физика, обучение, RNG, схемы результатов и статистические формулы не меняются. Снимки мира 0.50 совместимы. Измеренного ускорения не заявляется.

Код/контракт: [рабочее окно](../ui-redesign.md), [маршрут статистики](../navigation/experiments-and-statistics.md#statistics).
