# 0.33.2 — живое переключение вычислителей и понятные замеры

17 октября2026. Локальный выпуск. Модель длительных действий и геномv12 сохранены. Публикация этого выпуска не выполнялась.

## Управление миром

«Мир → Производительность» содержит подвкладки «Вычислители» и «Измерения». В первой — Авто/1/2/4/6/8/10/12/14/16, фактическое число, сведения CPU и явная кнопка применения. Стартовые условия содержат только настройки мира. Выбор в поле не меняет режим до применения; следующий новый мир использует применённую настройку. Авто остаётся консервативным1/2/4, разрешается при применении/создании, постоянной адаптации нет.

Переключение выполняется в очереди команд после полного шага. Старый пул возвращает полные память, обучение, незавершённый процесс и диагностику, новый подтверждает запуск и регистрацию всех мозгов без наблюдения, обучения или RNG. Только после всех подтверждений старый пул закрывается. При отказе сохраняются прежний пул и режим запуска. Шаг, жители, история, выбранный организм и след не сбрасываются. При возврате к последовательному расчёту очищается удалённая сводка численности памяти, чтобы история читала актуальные локальные Map. Однократное копирование оплачивается только при переключении, не на каждом подшаге. Во время переноса временно существуют старый и новый пулы/полные копии опыта.

При успешной смене фактического числа текущий профиль завершается с причиной `compute-workers-changed`, сохраняя измеренные данные старой конфигурации. Режим наблюдения сохраняется; время подготовки не накапливает долг шагов. Изменение Авто/ручного выбора без изменения фактического числа не завершает профиль. Механики, частота внимания/обучения и все RNG прежние.

## Постоянные замеры

Единая форма: версии, под каждой галочки поддерживаемых размеров пула, прежние группы оценщиков/миров и независимые числа повторов.0.32 поддерживает1;0.33.0 —1/2/4;0.33.1 и0.33.2 — до16. По умолчанию выбрана новая версия с1/2/4. Исторические снимки не расширяются ради новых галочек.

Отчёт `big-evolution-benchmark` v5, методика `rotating-version-worker-v1`. Каждый оценщик измеряется один раз на версию, не на каждый размер пула. Полные миры150/400/1000 измеряются на выбранных размерах. Один исходный снимок на версию/нагрузку, ротация режимов, отдельный прогрев каждого повтора, один активный пул. Подготовка/прогрев/хеши/явные уступки очереди вне computeMs; обмен и ожидание владельцев внутри шага. Полное чтение опыта для итогового хеша вне таймера; отбрасываемый прогретый опыт не пересылается полностью.

Таблица имеет общий заголовок версии и подстолбцы размеров. Оценщик занимает одну объединённую ячейку версии. Для мира показаны медианное время, диапазон/разброс, шаги/с, ускорение S=t_base/t_N, процент скорости100·(S−1) и эффективность100·S/(N/N_base). База — минимальное выбранное число своей версии; для сравнения с одним следует оставить1. Эффективность не является загрузкой CPU. Абсолютного выигрыша/сэкономленных миллисекунд и автоматического выбора нет. Неполные/разные итоги не получают ускорения; совпадение между версиями проверяется отдельно. Ошибка/остановка сохраняет полученные повторы. Прежние отчётыv1–v4 читаются без изменения их содержания.

## Тексты и ползунки

[ui-text.js](../../dist/ui-text.js) — общий каталог подсказок и статических пояснений страницы, включая71 абзац; help.js отвечает за диалог. Версия подвала берётся из MODEL_VERSION; ключевые числовые пояснения импортируют действующие константы. Разметка содержит ссылки `data-ui-text`, неизвестный ключ обнаруживается проверкой. Статические описания содержат только доверенную проектную разметку. Изменения подгружаются при обновлении страницы, на GitHub — после публикации файлов. Динамические показания тела/мира продолжают формироваться по текущим данным.

Ползунки всех форм имеют круглый контрастный бегунок26px в Chromium/24px в Firefox и область по высоте36px. Центральный период ограничен10…300 во всех трёх формах и общей валидации. Прежняя физическая граница индивидуального периода1600 сохранена отдельно: при разбросе его значение может быть выше300. Настройка300±90% не обрезается скрыто до300. Остальные физиология/расписание/RNG прежние.
