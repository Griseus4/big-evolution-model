# P00: исходный реестр охвата справочника

Пользователь поручил выполнить часть подготовленного плана по усмотрению исполнителя. Выбран P00: инвентаризация и фиксация границ описания. Версия приложения остаётся 0.54.8; код приложения и AGENTS.md не менялись.

Создан [реестр](../guide-plan/coverage.md) с таблицами рабочих модулей, проверок/фикстур и документов/инструментов/конфигураций. Каждому файлу назначены статья-вход и этап; предполагаемые маршруты отделены от подтверждённых указателями карточек и реестра статей. Для больших модулей отдельно перечислены обязанности разных этапов. Отпечатки SHA-256 фиксируют исходную точку, не доказывая смысловую полноту.

Сопоставлены все 18 статей и их прежние reviewedVersion: шесть имеют отметки прошлой содержательной сверки; остальные не объявлены полными. Проверены наличие панелей, выжимок, поисковых терминов и источников. Новая содержательная сверка всех механик не выполнялась; неизвестные части остаются явно непроверенными.

Рабочий список сверён с автоматическим инвентарём. Дополнительно учтены файлы вне него, а производные копии, архивные документы, расчётные снимки и старый локальный перенос исключены с основаниями. Отдельно записано расхождение package.json и версии приложения для P27; номер не исправлялся без выяснения назначения.

Проверки: структурная сверка файлов/реестра и `python tools/verify-local.py --only docs`; окончательные числа и результат — в контрольной записи. Симуляции, измерения скорости и настоящий браузер не требуются этому документальному этапу и не запускались. Готовый блок публикуется в существующий GitHub-репозиторий по постоянному поручению; deploy не проверяется.
