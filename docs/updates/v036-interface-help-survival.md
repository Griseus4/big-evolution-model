# 0.36.2 — подсказки, справочник и статистика дожития

## Результат

Исправление интерфейса 0.36.1 по скриншотам пользователя, без изменения игровой физики, мозга, RNG и распределений пищи. Публикация не выполняется.

- Скрытое поле загрузки не порождает одинокую кнопку «?». У ползунка и связанного числового ввода одна общая подсказка. Ввод/checkbox не содержит интерактивной кнопки помощи внутри label.
- Подсказки полей выровнены по строке ввода; кнопки случайного seed находятся на уровне ввода. «Следующий» имеет минимальную высоту 42 px и ширину 120 px.
- Открытие подсказки не вызывает паузу. Нативный диалог сохраняет клавиатурную навигацию и возврат фокуса. Пауза при переходе в другие основные вкладки остаётся прежней.
- «Правила мира» перенесены из верхнего диалога в тематические статьи «Об игре». Оглавление содержит ветки «Начало работы / Жизнь и поведение / Среда и питание / Исследование» и вопросы новичка. Это обычные доступные вкладки с визуальной иерархией, без отдельной сложной роли tree.
- «Автосреда» заменена вопросом об изменениях источников пищи. Числа расходов форматируются с максимумом четырьмя дробными знаками; вычислительные значения не округляются. Исправлено старое описание отсутствия урона от мышления: действующий с 0.36.0 дефицит уже переводится в здоровье.

## Кривая дожития

По подтверждению пользователя средний и медианный возраст смерти рассчитаны **только по завершённым жизням** выбранного интервала рождения и происхождения. Они отображаются вертикальными линиями и числами под графиком. Подписи находятся на разных строках, чтобы совпадение значений не слило текст.

Живые не включаются; до завершения их жизней значения могут занижать итоговую продолжительность жизни группы. Открытый интервал рождения дополнительно отмечен. При отсутствии завершённых жизней или `omittedDetails > 0` числовые линии отсутствуют. Прежние границы неизвестного исхода для живых сохранены; статистическая модель выживания не вводится.

Сумма возрастов накапливается при существующем отборе, медиана использует уже отсортированный массив. Две отметки кэшируются вместе с группой; перерисовка не повторяет отбор и сортировку. Новых обходов карты/сообщений Worker нет.

## Совместимость и проверка

Полные сохранения 0.36.0 и 0.36.1 читаются без изменения формата. Расчётное ядро бенчмарков остаётся замороженным 0.36.1: новый численный снимок для интерфейса не нужен.

Полный `python tools/verify-local.py` прошёл за 38,67 с: **154/154 Node-теста, 36/36 механизмов**, запуск, 452 JS/362 DOM ID/справка, документы и 338 файлов снимков против Git/SHA. Отчёт `.transfer/v0362-verification.json`. В том числе проверены настоящий установщик подсказок, одна кнопка на пару полей, отсутствие вызова паузы, среднее/медиана с живыми и неполной историей, положение вертикальных линий и продолжение сохранений с метками 0.36.0/0.36.1. Браузерное управление недоступно: реальный внешний вид, размеры и клики не объявляются проверенными. Длительные опыты и серии производительности не запускались.
