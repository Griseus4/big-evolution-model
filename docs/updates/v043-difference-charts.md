# 0.43.0 — читаемая статистика и временные разности

Статус: реализовано локально. Расчёт мира, геном, личное обучение, RNG и правило выбора итоговых попыток прежние. Расчётный снимок 0.39.2 не изменялся.

## Управление

Общая пара A/B выбирается в «Настройки статистики → Общая пара A/B». Она используется таблицей сравнения и всеми карточками. У каждой временной карточки свой список «Исходные данные / Разность B−A». Переключение одной не меняет остальные. Нужен источник «Сравнение вариантов»; для одиночного мира показано пояснение. Гистограммы чувствительностей и отдельная кривая дожития по возрасту остаются исходными.

Разность относится к выбранной линии среднего/медианы/минимума/максимума. У показателей одной доли используется среднее. Полоса по умолчанию — поточечный 95% ДИ **разности оценок**, не разность границ двух отдельных ДИ. Для среднего/медианы действует тот же парный оценщик, что и в таблице: 999 совместных перевыборок исходных повторов, от пяти полных пар. Медиана B минус медиана A не равна медиане индивидуальных парных разностей. Для экстремумов ДИ не оценивается.

Каждый временной интервал использует свой пригодный состав. Наведение сообщает число полных пар/пропусков и границы; неизвестность не становится нулём. Разные seed итоговых попыток сохраняют исходную пару по номеру повтора. Поэтому сравниваются настройки **вместе с правилом повторных попыток**, а не изолированное воздействие на одинаковых жителей. Малое число повторов и множество графиков ограничивают уверенность выводов.

Альтернативная полоса «Разброс миров» показывает квартильный диапазон разностей мировых средних/медиан; это не ДИ центрального эффекта. Ось разности симметрична относительно нуля, ноль отмечен пунктиром. Числа под графиком относятся ко всему общему периоду, наведение — к отдельной точке.

## Читаемость

- Гистограммы чувствительностей используют корзины шириной 20 п.п.; +100% включён в последнюю. Линейных дублей чувствительностей нет.
- Оценки и границы ДИ показывают один знак после запятой; точность расчёта/JSON сохраняется. Интервалы могут быть асимметричными, поэтому остаются двумя границами.
- Значение и целый ДИ — два неразрывных фрагмента, перенос возможен на пробеле между ними. Названия переносятся по словам. Число колонок адаптивное, карточка рассчитана на читаемую ширину; на узком экране таблица прокручивается внутри карточки.
- Возраст дожития находится в карточке соответствующей доли, причина прерываний — в карточке частоты прерываний. На экране таблицы пары есть синхронизированные поля этих же настроек.
- В «Ресурсах» появились среднее здоровье и среднее самочувствие, включая отрицательную часть шкалы чувств. Используются уже записанные средние за жизнь; нового опроса организмов нет. Всего в таблице пары 25 показателей.

## Стоимость

`pair-series.js` за проход истории готовит числовые выборки периода/корзин. `history-differences-ui.js` запрашивает только видимые карточки разности. Полные истории/мозги не передаются в Worker, буферы передаются без копирования. Общий парный оценщик сортирует выборки один раз, переиспользует кратности бутстрэпа и ограниченную CDF. Смена линии, полосы или размера не пересчитывает готовые оценки; смена A/B/фильтров прекращает устаревший запрос. В ответах точек нет тяжёлых списков миров; они остаются у периодной сводки. Исходные оценки для карточки разности не запрашиваются дополнительно.

Полные сохранения 0.39.2–0.42.0 остаются совместимыми. Это UI/аналитический выпуск, не новая биологическая модель.
