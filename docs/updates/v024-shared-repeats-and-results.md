# 0.24.1 — общие повторы и результаты 0.24

## Интерфейс

Одна кнопка «Показать повторы» на нагрузку раскрывает все версии в общих строках:
повтор №N имеет значения рядом на одной высоте. Незавершённый — «Ещё не завершён».
Повторное нажатие сворачивает нагрузку. Раскрытие сохраняется при новых результатах,
отдельно для текущего/загруженного отчёта. Подробный DOM создаётся только при раскрытии.
Native button, aria-expanded/aria-controls, уникальные ID, клавиатурное управление.
Таймеры/Worker/ротация/модель/снимки/JSON v1–v3 прежние. MODEL_VERSION выпуска
0.24.1, расчётный снимок 0.24.0. Чистому UI отдельный снимок не нужен.
Автоматического удаления замеров нет.

## Чувствительность к выбросам

Пользователь открывал ChatGPT во время world1000, включая 0.24. JSON не содержит
отметок переключения; нельзя достоверно связать событие с повтором. Замеры 12–20 с
вместо обычных 3.5–4 с согласуются с внешней нагрузкой, но не доказывают её причину.
Исходные значения сохранены; основное сравнение использует все 15.

Дополнительное правило: отдельно для каждой версии Q1/Q3 — медианы нижней/верхней
семёрки отсортированных 15 значений без центрального. Пометить время > Q3+1.5×IQR.
Если помечен номер хотя бы одной версии, исключить всю тройку с этим номером.
Это симметричная проверка чувствительности, выбранная после просмотра, не основной
результат и не доказательство статистической значимости/причины выброса.
Пороги 4382.7/4126.8/4260.0 мс; исключены номера 1,2,5,6,7 у всех трёх версий.
Осталось 10 троек: медианы 3920.25/3762.00/3586.30 мс.
0.24 относительно 0.22: −4.67%, относительно 0.20: −8.52%. Вывод сохраняется.
