# Конструктор анализа: инструкция для 0.47

Конструктор строит новые показатели и графики по **одному уже рассчитанному опыту**. Повторно запускать миры для этого не нужно. Работают полные результаты JSON и архивы `.beexp`. Файл генома, план запуска и полный снимок живого мира имеют другое назначение.

## Как открыть

1. Во вкладке **Опыты → Запуски** открой результаты опыта или дождись расчёта миров.
2. Перейди в **Статистику** и нажми **Конструктор анализа** рядом с заголовком. Этот же экран доступен в боковом списке **Экран**.
3. Проверь название опыта над редактором. Конструктор использует этот опыт независимо от поля «Источник статистики» прежних экранов.
4. Задай показатель, период, группы и нажми **Построить**. Пересчёт запускается явно; изменение формы само не запускает тяжёлую обработку.

Настройки периода, весов и групп находятся **в самом конструкторе**. Старые боковые настройки относятся к прежним графикам. Можно работать с частично завершённым опытом, но неготовые миры будут видны как пропуски.

## Сравнить обучение, объединив несколько вариантов

Для опыта «обучение да/нет × усвоение 2/5/20 Т»:

| Поле | Значение |
| --- | --- |
| Название | Продолжительность жизни по обучению |
| Значение или формула | `age` |
| Условие отбора | `true` |
| Расчёт | Среднее или медиана |
| Состояние жизней | Только завершённые жизни |
| Группировать по | Личное обучение |
| Дополнительно разделить по | Не разделять |
| Ось X | Период рождения родителей |

Выбери период рождения и ширину интервала, например 500 Т. Получатся две группы, каждая объединяет три времени усвоения. Чтобы получить три группы по усвоению, поменяй **Группировать по** на **Усвоение одной порции, Т**. Чтобы видеть все шесть сочетаний, добавь второй параметр в **Дополнительно разделить по**.

В блоке **Какие значения настроек включать** сними ненужные значения. Например, оставь только 5 и 20 Т. Фильтры применяются совместно: внутри одного параметра подходят все отмеченные значения, между параметрами должны выполняться все условия. Пустой выбор исключает все соответствующие варианты.

**Вариант опыта** позволяет сравнить исходные сочетания по ID. **Геном из файла**, если он был фактором, использует категории с номером и названием файла; сами гены не усредняются.

## Возраст рождения второго, третьего и последующих детей

Для возраста второго рождения введи `birthAge(2)` в формулу. Либо задай **Номер ребёнка → 2** и нажми **Выбрать возраст этого рождения**. Выбери среднее или медиану. Для третьего рождения замени номер на 3; допустимы номера 1–1000.

Чтобы увидеть последовательность рождений на одном графике:

| Поле | Значение |
| --- | --- |
| Значение или формула | `birthAge(N)` |
| Ось X | Номер ребёнка |
| Номера детей от 1 до | Например, 4 |
| Расчёт | Среднее или медиана |
| Группировать по | Например, личное обучение |

Для такой оси разрешено до 20 номеров. `N` означает номер на оси X. Период по-прежнему отбирает **время рождения родителей**; дети могут родиться позже этого периода. Чтобы учитывать уже состоявшиеся рождения у живых родителей, выбери **Все, включая живых**. Такие результаты предварительные.

Возраст N-го рождения рассчитывается только по особям, у которых оно наблюдалось. Если четвёртого ребёнка нет, значение отсутствует, а не равно нулю. При неполной истории невозможно надёжно установить порядок событий. В таблице показываются наблюдения/отобранные особи; нажми строку для состава миров и пропусков.

## Создать свой показатель

Можно выбрать поле из списка и вставить его в формулу. Поле вставляется в позицию курсора; для полной замены сначала выдели прежний текст. Десятичный разделитель **в формулах** — точка.

| Задача | Формула | Расчёт |
| --- | --- | --- |
| Средняя продолжительность завершённой жизни | `age` | Среднее; только завершённые |
| Медианный возраст третьего рождения | `birthAge(3)` | Медиана |
| Интервал между вторым и третьим ребёнком | `birthAge(3) - birthAge(2)` | Среднее или медиана |
| Доля особей без детей | `children == 0` | Доля выполнения условия, % |
| Доля достигших N-го рождения | `!missing(birthAge(N))` | Доля; ось — номер ребёнка |
| Порций на 100 Т жизни одной особи | `100 * eaten / age` | Среднее или медиана |
| Доля наблюдаемой жизни с нулевой энергией | `100 * emptyEnergySteps / observedSteps` | Среднее или медиана |
| Вызовов мозга на 100 Т | `1000 * observations.brainCalls / observedSteps` | Среднее или медиана |
| Средний переносимый запас | `observations.meanInventory` | Среднее |
| Чувствительность к энергии | `heritable.senseEnergy` | Среднее или медиана |

`observedSteps` и `emptyEnergySteps` в текущей модели считаются в подшагах: 10 подшагов = 1 Т. Формула частоты вызовов учитывает это. `age` и `birthAge` измеряются в Т.

Условие отбора — дополнительный фильтр особей, например `age >= 100 && children > 0`. `true` оставляет всех, прошедших остальные фильтры. Состояние жизней, происхождение и период применяются отдельно от формулы.

Доступны `+`, `-`, `*`, `/`, `%`, скобки, сравнения `==`, `!=`, `<`, `<=`, `>`, `>=`, логические `&&`, `||`, `!` и функции `abs(x)`, `min(x,y)`, `max(x,y)`, `missing(x)`, `birthAge(N)`. Деление на ноль, отсутствующее поле или отсутствие нужного рождения дают пропуск. `missing(x)` позволяет явно посчитать долю таких случаев. Произвольный JavaScript не исполняется.

Формула сначала вычисляется **для каждой особи**, затем агрегируется. Средняя частота отдельных особей отличается от отношения общих сумм еды и возраста. Вложенные агрегаты, произвольные программы и SQL в эту версию не входят. **Количество на мир** считает отобранных особей каждого мира и усредняет мировые количества; **Сумма на мир** аналогично усредняет мировые суммы известных значений. Они не означают общее количество/сумму по всему опыту.

## Как читать веса, пропуски и интервалы

- **Равный вес миров:** каждый непустой мир получает одинаковый суммарный вес; внутри него особи равноправны. Медиана считается по индивидуальным значениям с этими весами, не по медианам миров.
- **Равный вес особей:** каждая пригодная особь получает одинаковый вес. Многочисленные миры влияют сильнее. Выбор относится к среднему, медиане и доле; количества/суммы на мир всегда имеют равные веса миров.
- Для каждой точки нужны данные **всех выбранных сочетаний этой группы** внутри исходного повтора. Если одного сочетания нет или показатель отсутствует во всём его мире, этот повтор исключается из данной точки. Число исключений видно; строки отдельных миров можно раскрыть. Нельзя трактовать пустую ячейку как нуль.
- «Наблюдений / отобрано» относится к включённым в оценку мирам. В раскрытии видны и исключённые миры, их известные/пропущенные значения и живые особи. Исходные результаты не удаляются.
- При пяти повторах и трёх временах усвоения группа содержит 15 миров, но **5 независимых блоков повторов**. Для ДИ целиком перевыбирается исходный повтор со всеми его вариантами.
- Приближённый поточечный 95% ДИ показывается от пяти полных повторов. При 5–9 он особенно неточен. Вертикальные отрезки на графике и границы в таблице относятся к оценке, а не к разбросу отдельных особей. Нулевой наблюдаемый разброс не доказывает точность; пересечение интервалов не доказывает равенство групп.
- Сохраняется прежнее правило итоговой попытки: после вымирания могла использоваться новая попытка с другим seed. Это сравнение вместе с правилом повторов; номера попыток и все вымирания раскрываются.

## Сохранение и удобство

**Сохранить шаблон** сохраняет определение в этом браузере. Одинаковое название заменяет прежнее определение; доступно до 50 шаблонов. **Открыть шаблон** переносит его в форму, но не запускает расчёт. **Скачать шаблон** выгружает небольшой JSON с формулой/фильтрами/оформлением; соседнее поле загружает такой файл. Исходные данные миров в шаблон не входят: сначала открой подходящий опыт. Шаблон с отсутствующим фактором не применяется молча к другому опыту.

Выбери линии, столбцы или таблицу. После изменения вида нажми **Построить**: если изменены лишь название/вид, а данные и расчётные настройки прежние, используется сохранённый результат. Изменение размера окна не пересчитывает статистику. **Отменить расчёт** останавливает подготовку/Worker и сохраняет предыдущий готовый результат.

Ограничения: до 400 временных точек и до 600 ячеек «группа × X». При превышении увеличь временной интервал или сократи группы. Для N-го рождения понадобится чтение связей за пределами периода родителей: обработка может быть заметно дольше обычного графика. Новые показатели возможны только из записанных данных; полных траекторий и незафиксированных встреч конструктор не восстанавливает.

Перестройка вкладок/интерфейса отложена на возможное следующее обновление. [Технический протокол 0.47](updates/v047-analysis-builder.md).
