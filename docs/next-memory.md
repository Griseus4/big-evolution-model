# Этап личной навигации и памяти

**Статус: реализован в 0.6.** Пользователь разрешил все требования, затем попросил продолжить. Прежние открытые Q1–Q3 разрешены. Численные диапазоны — выбранные параметры прототипа, допускающие дальнейшие изменения.

## Принятые решения

- Q1: собственная ориентация, случайный поворот при рождении; личное начало (0, 0). Точный учёт шагов, без ошибок навигации пока.
- Q2: автоматическое закрепление через повторные возвращения, сильное приятное/неприятное чувство и неожиданность. Отдельное действие «запомнить» отложено.
- Q3: пока без дополнительной энергетической цены памяти.
- Карта 48×32; прежние источники перенести группами по большой карте, не добавляя их и не меняя ёмкости/восстановление. Между островками пустое пространство.

## Будущие обсуждения, не разрешённые изменения

Цена мозга, ошибки пути и распознавание ориентиров, отдельное намеренное запоминание, более дальний горизонт критика, сезонность, новые угрозы, социальные действия. Не внедрять автоматически.

## Как проверить поведение

Сравнить у одного организма при одинаковом теле и геноме выбор с известным скрытым источником и без записи. Разделять режимы: без памяти/TD, память без TD, память с TD. Смотреть несколько seed и десятки тысяч шагов. Фиксировать возвращения конкретных живых жителей, а не только долю популяции у еды: гибель ушедших также создаёт концентрацию.
