# Вход в Big Evolution

Локальный выпуск **0.33.0**,17 октября2026. Общая физика/RNG — у координатора, личные память/внимание/обучение/оценки — у постоянных владельцев. Публикация0.33 не выполнялась. [Протокол](updates/v033-parallel-world.md).

Локальный запуск: `python -m http.server 8000 --bind 127.0.0.1 --directory dist`, затем http://127.0.0.1:8000/ .

## За минуту

- Карта48×32,150 основателей, лимит начала родов1000,384 источника. Начатые роды допускают превышениеN.
- Модель0.32 сохранена:10 подшагов=1Т; движение15, сбор5, еда2, ожидание5, выкладывание3, роды20. Прерывание сохраняет расходы; продолжение сохраняет прогресс.
- Геномv12: **1463 наследуемых** числа. Основной мозг1376, свойства12, малая сеть73, регуляторы2. Старые основы не импортируются.
- В новом опыте доступны Авто/1/2/4 вычислителя. Авто:1 при старте меньше32 особей или менее4 логических CPU;2 при4…7 CPU;4 при8 и более. Число фиксируется при старте.
- Два барьера на подшаг, исходный порядок RNG, буферы Float64 с возвратом владельцу. Полные мозги — только при регистрации, подробном просмотре или явном контрольном снимке.
- UI отдельно; пауза/правки/экспорт после целого шага. Apply пищевых условий сохраняет запуск. Внутренние вкладки ставят паузу, скрытие страницы программную паузу не включает.
- Замеры содержат0.32/0.33 в одной серии;0.33 считает миры пулом4. Длинные независимые испытания сохраняют последовательный расчёт каждого мира.

## Проверка и следующий шаг

13 специальных проверок пула и интеграционная проверка настоящих снимков прошли. Полный локальный набор прошёл за12,10с:81/81 Node,33/33 механизма, статика/запуск/документы и75 неизменяемых модулей снимков. Короткий парный Node-замер:2,22 /2,20 /2,38 раза на150/400/1000 особях, полные итоги совпали. Это4Т после3Т прогрева,3 повтора; карта/настоящий браузер не измерены. Браузерная сессия в этом сеансе недоступна.

Следующий предмет работы — отдельное исследование оптимизации по новому профилю, когда пользователь его поручит. В текущий патч широкое исследование не входит. WASM, новые механики и изменение частоты внимания не реализованы.
