## Активная задача

0.56.0 в работе: раздельные регуляторы весов/структуры, геном v17; итоговые проверки — в контрольной записи. P03b остаётся отменённым. Пособие: [охват](guide-plan/coverage.md), [ограничения](guide-plan/audit.md); новые правила отражены в главах генома и мутаций.

Каталог поддерживает общую панель и закрепления шаблонов; [карта изменений](navigation/README.md) содержит его код/проверки. [Рабочее окно и вкладки](ui-redesign.md) обновлены в 0.52; генератор карты и оптимизация остаются [предложениями](next-performance-map.md). [Правила поддержки](workflows/context.md) обязательны.

[Контрольная запись](work/current.md) — единственное место текущего хода работы: разрешённый объём, файлы, проверки и следующий шаг. Проверить её статус, не продолжать автоматически завершённые задачи или идеи. Готовность контракта и разрешение реализации различать.

GitHub обновлять из `D:/GitHub/big-evolution-model`: сверить ветки, затем commit/push без дополнительных тестов и проверок сайта. [Постоянный маршрут](workflows/local.md#публикация).
