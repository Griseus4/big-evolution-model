# Вход в Big Evolution

## Текущий статус

Рабочая версия — [0.46.0: время усвоения в опытах](updates/v046-digestion-experiments.md). Версия в `dist/life-history.js`, параметры — в коде. Без переопределения усвоение прежнее; общая пищевая среда [0.39.2](updates/v039-shared-food-seed.md) сохранена. Геном — в [механиках](mechanics-reference.md); [прежняя публикация](updates/v045-github-publication.md) относится к 0.45.

0.46.0 не проверялась тестами/мирами по пожеланию пользователя; подготовленные проверки перечислены в протоколе. Старые успехи не подтверждают новую версию. [Маршрут проверок](verification.md).

## Активная задача

Параметр усвоения реализован в конструкторе; [карта изменений](navigation/README.md) обновлена у энергетики/планов. Генератор, контроль устаревания и оптимизация остаются [предложениями](next-performance-map.md). [Правила поддержки](workflows/context.md) обязательны.

[Контрольная запись](work/current.md) — единственное место текущего хода работы: разрешённый объём, файлы, проверки и следующий шаг. Проверить её статус, не продолжать автоматически завершённые задачи или идеи. Готовность контракта и разрешение реализации различать.

GitHub обновлять из `D:/GitHub/big-evolution-model`: сверить ветки, затем commit/push без дополнительных тестов и проверок сайта. [Постоянный маршрут](workflows/local.md#публикация).
