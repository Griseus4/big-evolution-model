Локальный выпуск **0.33.2**,17 октября2026. [Живые вычислители, таблица версий/режимов, тексты и ползунки](updates/v033-live-controls.md). Выбор до16 вычислителей и сравнение режимов одного стандартного мира — [новый протокол](updates/v033-worker-counts.md). Общая физика/RNG — у координатора, личные память/внимание/обучение/оценки — у постоянных владельцев. Публикация0.33 не выполнялась. [Протокол](updates/v033-parallel-world.md).

Локальный запуск: `python -m http.server 8000 --bind 127.0.0.1 --directory dist`, затем http://127.0.0.1:8000/ .

## За минуту

- Карта48×32,150 основателей, лимит начала родов1000,384 источника. Начатые роды допускают превышениеN.
- Модель0.32 сохранена:10 подшагов=1Т; движение15, сбор5, еда2, ожидание5, выкладывание3, роды20. Прерывание сохраняет расходы; продолжение сохраняет прогресс.
- Геномv12: **1463 наследуемых** числа. Основной мозг1376, свойства12, малая сеть73, регуляторы2. Старые основы не импортируются.
- В новом опыте доступны Авто/1/2/4/6/8/10/12/14/16 вычислителей. Авто:1 при старте меньше32 особей или менее4 логических CPU;2 при4…7 CPU;4 при8 и более. Меняется без перезапуска через «Производительность → Вычислители»; «Измерения» — отдельная подвкладка.
- Два барьера на подшаг, исходный порядок RNG, буферы Float64 с возвратом владельцу. Полные мозги — только при регистрации, подробном просмотре или явном контрольном снимке.
- UI отдельно; пауза/правки/экспорт после целого шага. Apply пищевых условий сохраняет запуск. Внутренние вкладки ставят паузу, скрытие страницы программную паузу не включает.
- Замерыv5: выбранные версии0.32/0.33.0/0.33.1/0.33.2 с вложенными галочками размеров пула; миры150/400/1000 на каждом выбранном размере, оценщики один раз на версию. Показаны шаги/с, ускорение и эффективность, без автоматического подбора. Длинные независимые испытания сохраняют последовательный расчёт каждого мира.

## Проверка и следующий шаг

**0.33.2:** полный набор прошёл за18,12с: 99/99 Node,33/33 механизма, синтаксис/DOM, документы, запуск и157 модулей снимков против Git/SHA. Подтверждены полные траектории живого переключения и новый исполнитель настоящих Worker. Браузер: интерфейс, ползунки, max300, переключение после шага,3/3 оценщика. Полные серии миров не запускались; наиболее быстрый режим не выбран. Отчёт `.transfer/v0332-verification.json`.

**0.33.1:** полный локальный набор прошёл за16,37с:90/90 Node и33/33 механизма, синтаксис/DOM-связи, документы/ссылки, инициализация и116 неизменяемых модулей снимков. Новые числа вычислителей дают совпадающие полные состояния; панель проверена в минимальном DOM, настоящая браузерная отрисовка не проверялась. Полные сравнительные серии не запускались; следующий практический шаг — пользовательский замер выбранных размеров пула на одной нагрузке.

**Исторический результат0.33.0:**13 специальных проверок пула и интеграционная проверка настоящих снимков прошли. Полный локальный набор прошёл за12,10с:81/81 Node,33/33 механизма, статика/запуск/документы и75 неизменяемых модулей снимков. Короткий парный Node-замер:2,22 /2,20 /2,38 раза на150/400/1000 особях, полные итоги совпали. Это4Т после3Т прогрева,3 повтора; карта/настоящий браузер не измерены. Браузерная сессия в этом сеансе недоступна.

Следующий предмет работы — отдельное исследование оптимизации по новому профилю, когда пользователь его поручит. В текущий патч широкое исследование не входит. WASM, новые механики и изменение частоты внимания не реализованы.

**История обсуждения, выполнено в0.33.2:** исправление версии/подсказок, перенос выбора вычислителей в «Производительность → Вычислители / Измерения», разрешённое переключение живущего мира, версии с вложенными размерами пула в замерах и показатели эффективности. Оценщики один раз на версию; автоматический подбор отложен. Реализация и проверки завершены. Направление и вопросы — в конце [идей](future-ideas.md). У заново созданного GitHub-репозитория workflow остановился на выключенном Pages; владельцу дан маршрут включения, успешная публикация пока не подтверждена: [диагностика](github-pages.md#повторное-создание-репозитория17-октября2026).
