## Что заявлять о текущей версии

По текущему коду MODEL_VERSION=0.31.3: браузерная JS-модель, один вычислительный Worker отдельно от UI, гексагональный мир, наследуемый нейросетевой мозг, личное Expected SARSA(λ), память мест, ограниченная пища/энергия, добровольное рождение и мутации. Текущий геномv11/990 чисел,975 нейронных параметров. Планы стаи/вожака — цель исследования. Подшаги/длительности/платное мышление/малый мозг пока не реализованы и не должны попасть в перечень возможностей выпуска.

Не позиционировать приложение как Python-симуляцию: Python обслуживает инструменты, а игра и вычисления написаны на JavaScript. Показатели1280 шагов/с и загрузка всего CPU не достигнутые гарантии; реальный выигрыш0.31.3 описан в [протоколе](updates/v031-shared-decision-inputs.md).

## Предложенная структура без переделки кода

Сохранить нынешние dist/, docs/, tests/, tools/ и package.json. Сейчас dist/ содержит и рабочие JS-исходники, и статические ресурсы. Перенос в src/ потребует изменения путей/упаковки и не нужен ради первой публикации. Будущий основной README следует сделать коротким, а docs/START_HERE.md оставить входом в подробную документацию.

Поле private:true относится к npm-пакету, не определяет публичность GitHub.
3. Выбрать публичность репозитория и лицензию. Файл LICENSE в текущих отслеживаемых файлах не найден; решение за пользователя не принимать.
